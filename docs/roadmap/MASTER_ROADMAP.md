# SyphonNov 产品与教学能力总路线表

更新时间：2026-09-10

当前开发版本：v0.4.4

规划分支：`plan/v0.5-plus-roadmap`

## 1. 产品目标

SyphonNov 的长期目标是成为一款可视化节点化、交互体验优秀、轻量、数值可信的科研绘图与数学教学软件。交互理念参考 Blender 的直接操作、资产架、节点编辑器和工作区组织方式，但所有行为必须服从科研数据语义与可复现要求。

路线表中的“完备”分成三层：

1. **图元完备**：点、线、曲面、文本、色带能够在二维或三维坐标系中组合。
2. **科研表达完备**：尺度、误差、图例、多面板、矢量导出和拟合诊断能够满足常见论文绘图。
3. **教学表达完备**：标量场、向量场、动力系统和复变函数可以生成、分析、联动演示并导出课程材料。

“支持所有科研绘图”不是封闭集合。每个正式版本都必须更新 capability matrix，公开支持的数据类型、尺度、误差语义、规模边界、导出格式和验证证据。

## 2. 已确认的产品决定

- v0.4.1 直接删除 `plane_input`，新增 `surface_input`，不提供旧节点兼容或自动迁移。
- 平面作为曲面的 `plane` 预设存在，不再拥有单独节点类型。
- 含 `plane_input` 的旧工作流在 v0.4.1 中原子拒绝，并明确指出不受支持；不得静默丢弃节点。
- 顶部节点提示条按五个现有类别自动读取注册表：输入、数据初步、计算、转换、可视化。
- 节点从顶部拖出时显示为分类色圆点，落入画布后展开成节点卡片。
- 右键节点菜单、搜索和快捷键继续保留，作为并行的专业操作入口。
- 动画不得改变计算结果、拖动坐标或命中范围；节点和画布拖动必须直接跟手。
- 所有近似预览必须标记 LOD；计算和正式导出使用完整数据。

## 8. v0.5.0～v0.5.1：插件平台与 Num 插件

这里的插件是 SyphonNov 产品插件，不是开发工具插件。核心应用只提供稳定、受限的扩展接口；关闭插件后，基础绘图、工作流执行和文件打开能力仍然成立。

两个首发插件暂定名：

- **SyphonNum**：观察每个节点的实际执行记录，讲解算法、数值误差、数据布局和类型转换，不改变节点计算结果。
- **SyphonEdu**：注册标量场、向量场、复数场、流形等教学数据类型、节点、查看器和课程场景。

## 15. 路线表维护规则

- 状态只使用：`待排期`、`已排期`、`实现中`、`已验证`、`延期`。
- 新需求先进入本表并获得 ID，再进入版本开发分支。
- 每个版本只选择共享数据模型、渲染基础或交互基础设施的一组功能。
- 功能进入“已验证”需要同时满足：实现、反例测试、界面说明、教学记录或用户文档、发布检查。
- 版本开发中发现硬缺陷时，先修复硬缺陷，再继续增加能力。
- 任何延期必须写明原因、依赖和重新评估版本，不允许从表中直接删除。
- 每次发布后把实际完成项改为“已验证”，把未完成项移到明确的新版本。
