# 尺度不变性与异步快照：v0.3.6 反例教学记录

这份笔记解释深度审查中两个最值得学习的主题：为什么固定绝对阈值会把可解方程变成零解，以及为什么“任务按顺序执行”仍可能得到旧结果。

## 1. 一个算法应尊重什么尺度变换

考虑线性方程组

\[
Ax=b.
\]

把等式两边同时乘非零常数 \(\alpha\)，得到

\[
(\alpha A)x=\alpha b.
\]

它与原方程有完全相同的解。这个性质称为尺度不变性。若算法对 \(A=I,b=(1,2)^T\) 返回 \((1,2)^T\)，却对

\[
A=10^{-20}I,\qquad b=10^{-20}(1,2)^T
\]

返回 \((0,0)^T\)，错误来自算法而非浮点数无法表示答案。

v0.3.6 用

```text
abs(pivot) < 1e-12
```

判断主元是否为零。这个条件带有输入单位：把米换成纳米或把矩阵整体缩放，就会改变真假。更合理的判据要相对于矩阵或当前行/列尺度，例如

\[
|a_{kk}| \le C\,\varepsilon_{mach}\,\|A\|,
\]

并结合带主元的 QR、LU 或 SVD 判断数值秩。阈值常数、范数和秩判据需要在接口中有明确含义。

### 奇异系统为什么不能补零

系统

\[
\begin{bmatrix}1&1\\2&2\end{bmatrix}
\begin{bmatrix}x_1\\x_2\end{bmatrix}
=
\begin{bmatrix}2\\4\end{bmatrix}
\]

只有一条独立方程，解有无穷多个。v0.3.6 跳过零主元并让未求分量保持初值 0，于是返回 \((2,0)\)。它确实满足方程，但不能被报告为唯一数值解。

正确接口至少应区分：

- 唯一解；
- 相容但不唯一；
- 不相容；
- 条件数过大，数值结论不可靠。

## 2. 中间量溢出不等于答案溢出

对 \(x=[10^{200},2\times10^{200}]\)，总体均值为 \(1.5\times10^{200}\)，标准差为 \(0.5\times10^{200}\)，z-score 正好是 \([-1,1]\)。

直接计算平方偏差会出现

\[
(0.5\times10^{200})^2=0.25\times10^{400},
\]

超过 double 上限，方差变成无穷大，最终得到带符号的零。可以先除以数据尺度 \(s\)：

\[
z_i=\frac{x_i/s-\bar{x}/s}{\sigma/s},
\]

或用稳定的在线方差算法。min-max 也应避免直接形成可能溢出的 \(x_{max}-x_{min}\)，可先缩放后计算比例。

这里应区分四类误差：

- **语义错误**：把文本分类值当缺失；
- **浮点舍入**：有限精度造成末位误差；
- **中间量溢出**：输入和答案有限，但计算路径产生无穷；
- **显示误差**：标签只显示若干位，不应反写内部数据。

## 3. 非均匀网格不能套均匀中心差分

均匀网格常用

\[
f'(x_i)\approx\frac{f(x_{i+1})-f(x_{i-1})}{2h}.
\]

在 \(x=[0,1,3]\) 上，左右步长分别为 \(h_s=1\)、\(h_d=2\)，跨点斜率

\[
\frac{f(3)-f(0)}{3-0}=3
\]

不是 \(f(x)=x^2\) 在 \(x=1\) 的导数 2。由二次插值可得

\[
f'(x_i)\approx
-\frac{h_d}{h_s(h_s+h_d)}f_{i-1}
+\frac{h_d-h_s}{h_sh_d}f_i
+\frac{h_s}{h_d(h_s+h_d)}f_{i+1}.
\]

它对所有二次多项式精确。重复横坐标使分母为零，应该拒绝或先定义合并规则，不能偷偷替换为 `1e-9`。

## 4. 串行任务为何仍会发生竞态

设初始结果为

```text
A=1, B=10
```

用户快速做两次修改：

```text
T1: A -> 2
T2: B -> 20
```

v0.3.6 在“排队时”给两个任务都拍下旧结果快照：

```text
T1.prev = {A=1, B=10}
T2.prev = {A=1, B=10}
```

队列保证 T1 先执行、T2 后执行：

```text
T1 落定 {A=2, B=10}
T2 只重算 B，并从自己的旧快照复用 A，落定 {A=1, B=20}
```

所以“串行执行”只保证任务顺序，不保证每个任务读取上一个任务刚提交的状态。修复方法有三类：

1. 任务真正开始时读取最新已提交结果；
2. 给图状态分配递增 revision，过期任务禁止提交；
3. 合并尚未开始的任务，对同一 revision 计算一次完整脏集合。

科学软件还应把结果和参数 revision 绑定。导出前检查两者一致，才能证明图对应当前参数。

## 5. 三类容差不能混为一个数

曲线求交至少包含三个不同问题：

- **相交谓词**：两线段是否相交；
- **交点去重**：多个线段对是否代表同一几何交点；
- **曲线分段**：两点之间是否允许连线。

v0.3.6 用精确二进有理数改进了第一个问题，但 `1/x` 的假根属于第三个问题，3000 点截断属于数据完整性，`1e-6*scale` 合并近邻交点属于第二个问题。一个局部精确算法不会自动修复整个流水线。

## 练习

1. 若把线性系统同时乘 \(10^{30}\)，准确解是否变化？固定 `1e-12` 主元阈值的判断是否可能变化？
2. 计算 \([a,2a]\) 的总体 z-score，说明答案为什么与 \(a>0\) 无关。
3. 用上面的非均匀三点公式验证 \(f(x)=x^2\)、\(x=[0,1,3]\) 的中点导数。
4. 为异步图执行设计一个 revision 规则，使旧任务永远不能覆盖新参数的结果。

<summary>参考答案</summary>

1. 准确解不变；固定绝对阈值的判断会随整体缩放改变，所以不满足尺度不变性。
2. 均值为 \(1.5a\)，总体标准差为 \(0.5a\)，故 z-score 为 \([-1,1]\)。
3. 代入 \(h_s=1,h_d=2\) 和函数值 \(0,1,9\)，结果为 2。
4. 参数或结构每次变化令 revision 加一；任务携带启动 revision，提交时只有任务 revision 等于当前 revision 才能覆盖结果。若需保留增量收益，可在新 revision 上合并所有未完成修改的脏集合。
