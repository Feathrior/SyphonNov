## P0：可能直接改变数据或最终结果

### AUD-001 后台增量执行会用旧结果覆盖新结果

快速把两个独立表格输入从 `1 → 2`、`10 → 20` 后，等待全部后台任务结束，第二个输入为 `20`，第一个却回退为 `1`。正确最终状态应为 `2` 和 `20`。

根因是每次排队时立即捕获 `prev = results`，但任务稍后才串行执行和落定。第二个任务捕获的仍是两次修改前的旧结果，并把“不脏”的第一个节点从旧快照复制回来。参见 `lib/store/graph_store.dart:1333-1382`。

影响：快速编辑、连续连接或脚本式修改时，界面最终显示的数据可能不对应当前参数。用户无法仅凭“任务都执行完了”发现错误。

修复标准：任务开始执行时读取前一个已落定结果，或使用单调 revision 丢弃过期结果；增加两个独立分支交错修改、同一分支多次修改和结构变更的确定性回归。

### AUD-002 CSV 与 XLSX 可损坏或拒绝常见数据

- 合法 CSV 字段 `"A\nB"` 被拆成两条记录；原两行观测变三行并错配数值。解析器先按换行拆记录，随后才处理引号，见 `lib/models/csv.dart:13-52`。
- 无表头混合数据 `A,1 / B,2` 自动把第一行当表头，第一条观测被无提示删除。产品没有显式“有表头/无表头”选项。
- 稀疏 XLSX 中第一行只有 A1、第二行出现 C2 时抛 `RangeError`。早期行按当时宽度创建，后续全局宽度变大后又索引旧行，见 `lib/models/csv.dart:152-208`。
- 文件入口接受 `.xls`，实现却只会按 ZIP/OOXML 解析 `.xlsx`；UTF-8 损坏字节采用 `allowMalformed` 静默替换。

影响：错误发生在所有计算之前，后续图形即使绘制正确也在表达错误数据。

### AUD-003 线性方程求解器会把可解问题算错，并把奇异问题伪装成解

- `diag(1e-20,1e-20) x = (1e-20,2e-20)` 的准确解是 `(1,2)`，实际返回 `(0,0)`。
- 奇异系统 `[[1,1],[2,2]] x = [2,4]` 没有唯一解，实际返回 `(2,0)`，没有报错。

根因是用无量纲意义不明的固定绝对阈值 `1e-12` 跳过主元，再把未求出的分量保留为零，见 `lib/models/math.dart:89-114`。多项式拟合又通过正规方程调用该求解器，会平方条件数，扩大同类问题。

影响：拟合系数可看似正常但并非算法求得的唯一可靠解。

### AUD-004 工作流文件不能复现随机预设数据

保存随机火山图预设并重新载入同一 JSON 后，多列数值全部改变。工作流只保存节点规则和参数，没有保存当次实现的数据或可重建的随机状态，见 `lib/store/graph_store.dart:1010-1017`。

影响：保存的图无法作为当次实验的可复现档案；同一文件可在不同时间生成不同结论。

## P1：科研语义或几何可信度错误

### AUD-005 表达式与内部舍入

- `2*x^2` 在 `x=3` 应为 18，实际为 36，说明乘法和幂的结合实现错误。
- `0.0000001*x` 在 `x=1` 应为 `1e-7`，函数曲线内部却得到 0。执行层广泛使用 `toStringAsFixed(4/5/6)` 再转回 double，把显示格式写进内部数据，见 `lib/models/exec.dart:363-366, 430-447, 717-823, 1034-1095`。

内部数据舍入会累积传播，不能用“导出时看起来整齐”解释。格式化只应发生在标签和表格显示层。

### AUD-006 非均匀差分和重复横坐标

在 `x=[0,1,3]`、`y=x²` 上，中点导数准确值为 2，实际中心跨点斜率为 3。重复横坐标本应拒绝，代码却用 `1e-9` 代替零分母并继续返回结果，见 `lib/models/math.dart:47-70`。

### AUD-007 标准化在有限极值上溢出

- `[1e200,2e200]` 的总体 z-score 应为 `[-1,1]`，实际为 `[-0,0]`。
- `[-1e308,1e308]` 的 min-max 结果应为 `[0,1]`，实际为 `[0,NaN]`。

输入与答案均为有限 double，失败来自中间平方或差值溢出。应先中心缩放，并采用稳定的在线方差或缩放范数算法。

### AUD-008 分类值被误判为缺失

`group=[control,treated]` 与 `response=[1,2]` 没有缺失值，启用删除缺失行后却从 2 行变为 0 行。代码用“能否转成数字”判断整行是否缺失，见 `lib/models/exec.dart:516`。

### AUD-009 间断点和缺失段被错误连接

显式 `1/x` 跨零采样时丢弃非有限点，然后把两侧有限点直接相连；与 `y=0` 求交得到不存在的 `(0,0)`。表格转曲线也直接跳过缺失行，前后观测被接成实线。v0.3.6 已让隐式曲线使用 NaN 分段，但没有把同一语义扩展到显式/参数曲线和表格曲线。

### AUD-010 求交仍有截断和分辨率语义

精确二进有理数方向判定修好了小尺度线段的相交谓词，这是 v0.3.6 的真实进步。但完整流程仍只取每条曲线前 3000 点，因此第 3001 点形成的末段被忽略；交点再按 `1e-6 * scale` 合并，近邻的两个真实交点可能变成一个。参见 `lib/models/exec.dart:838-944`。

### AUD-011 图表位置和数据量会无提示改变

- 标准散点输入 5001 行只画 5000 行，见 `lib/ui/viewer.dart:778-787`。
- 原理化散点 6001 个只画 6000 个，见 `lib/ui/principled.dart:836`。
- 折线表格 `x=[0,1,10]` 把中间点画在 50% 处，正确数值坐标应为 10%。
- 用户明确设置 `[0,1e-12]` 的坐标范围，执行层改成 `[0,1]`；视图和刻度又把小于 `1e-9` 的跨度当退化区间。
- 热力图只取前 10 个数值列、前 120 行；箱线图只取前 12 列；小提琴图只取前 8 列，均未在图中标注“部分数据”。

静默截断比明确拒绝更危险，因为图像仍能正常出现。

### AUD-012 图形统计定义不充分

- 箱线图把最小值和最大值直接作为须，没有 1.5 IQR 规则、离群点或规则选择。
- 小提琴图带宽硬编码为 Silverman 风格近似，且最低固定 `1e-6`，没有把带宽和归一化语义暴露给用户。
- 火山图硬编码 `|log2FC|>1` 与 `p<0.05`，没有阈值参数、原始/校正 p 值声明或显著性图例。
- 热力图会把每张图按各自极值重标色；色带范围只向外扩展，不能可靠固定跨图的同值同色。

## P2：工程完整性和产品边界

### 执行与工作流

- 完成一条 UI 连线时，`GraphStore.onConnect` 已触发增量执行，画布随后又调用一次全量 `runPipeline()`，见 `lib/ui/node_canvas.dart:1097-1124`。这会重复计算，并增加随机数据变化和后台队列竞态的触发机会。
- Isolate 失败时捕获所有异常并退回主线程同步执行，没有向用户提示；大任务可能重新阻塞界面。
- 没有取消、进度、队列合并或大数据性能门槛。采样数等参数缺少合理上限，可能创建超大列表。
- 画布加载只检查格式名和 nodes 是否为列表，不校验格式版本、ID 唯一性、边端点、端口类型或单输入多连。非 multi 端口收到多条边时由边顺序决定最后值。
- 保存文件没有软件版本、输入摘要、算法版本、随机状态、执行日志或结果校验值。

### 导出与出版

v0.3.6 只提供 PNG。宽高参数是像素数，没有物理页面尺寸和 DPI 元数据，也没有 SVG/PDF 矢量输出、字体嵌入检查、批量导出或多面板共享轴。PNG 可用于屏幕预览，但不足以覆盖常见论文和出版流程。

### 能力缺口

尚无原生 log/log-log/symlog/时间轴、误差条、置信带、拟合残差与参数区间、权重拟合、自动图例、多面板、共享轴/色标、等比例坐标、直方图产品节点、等高线/向量场，以及 HDF5/NetCDF/Parquet 等数据入口。工具不必内置所有学科算法，但误差表达、轴类型、图例、多面板和可复现导出属于通用科研绘图核心能力。

### 许可与安装

- README 两次声明 MIT 并链接 `LICENSE`，官方源码包中却没有 `LICENSE` 或 `LICENSE.md`。因此仅凭 README 链接不能确认实际许可文本；在补齐许可证前不宜公开再分发修改版。
- `install.nsi` 使用产品名 `SyphonNov2`，卸载登记版本固定为 `1.0.0`，与软件 `0.3.6+1` 不一致；安装要求管理员权限并默认写入 Program Files。
- `pubspec.yaml` 描述仍为 Flutter 模板文本 `A new Flutter project.`；没有 changelog、CI 配置或发布构建校验文件。

## 已确认的 v0.3.6 改进

审查没有否定新版的有效工作：

- 新增函数、参数和隐式三种曲线模式；隐式曲线分支用 NaN 隔开。
- 使用 double 的精确二进有理数表示改进线段方向判定，小尺度相交不再被固定绝对叉积阈值吞掉。
- 坐标系可收集多类图元，加入隐藏轴模式，并扩展到更多预制图。
- 引入邻接表、脏节点传播、单节点耗时和 Isolate 后台计算。
- Alt 拖线自动插入类型转换链，并改进菜单、滚动和参数显示。

这些改进主要增强架构与交互；后台执行竞态说明新架构仍需要并发正确性回归。

## 建议修复顺序

1. 先修后台任务 revision/快照规则、CSV/XLSX 解析和随机工作流复现。这三类问题会使“当前参数、当前文件、当前图”彼此不一致。
2. 替换线性求解和多项式拟合核心；去除内部十进制舍入；修表达式优先级、非均匀差分、标准化溢出，并用尺度变换回归验证。
3. 统一曲线分段数据模型，修复显式/参数/表格间断点；移除求交前缀截断，分别设计谓词、去重和性能策略。
4. 统一标准图和原理化图的坐标映射，删除静默数据上限；确需抽稀时采用可声明算法并显示原始/绘制点数。
5. 补误差条、置信带、log/time/等比例轴、图例、多面板和固定色标，再完成 SVG/PDF、物理页面与批量导出。
6. 补许可证、版本化安装器、CI 和发布清单，最后做真实窗口、安装/卸载与异机验收。
