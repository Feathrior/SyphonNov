## 行为变化与兼容性

旧工作流依赖错误幂规则、接受残缺表达式、默认随机变化、线性标签下的二次模型时，重算结果会改变。微积分要求X严格递增，不自动排序；必须先处理重复观测。空的微积分数据可继续传播，求导单点会给出说明。拟合参数表现在保留数值而非舍入后的字符串；常数响应R²显示空值。

指数拟合参数表保留前3个参数 `a,b,R²`，追加 `x_center,log_y_at_center` 和说明列。`ExpoFitResult.a` 现在为可空数值：无法表示的原点系数不写成零；调用 `evaluate(x)` 或使用输出中心化公式重建预测。

## 当前局限

1. 仍使用binary64，不提供任意精度、误差条、条件数估计或自动步长选择。极端数值范围可能溢出/下溢。
2. QR没有列主元或SVD；高度聚集节点/高阶拟合可能被数值秩检查拒绝。原坐标多项式系数可能病态，绘图使用缩放基底减轻抵消。
3. 差分端点是一阶；噪声放大仍存在。积分采用梯形法，Kahan只改善累加，不改变近似阶。
4. 指数拟合是对数空间最小二乘；无加权或原响应非线性最小二乘。原点系数 a 可能不可表示，此时参数表给出空值、说明及可用于计算的中心化参数；预测使用中心化对数模型。如果最终预测本身不可表示，明确报错，不返回零/NaN 伪装有效曲线。极端 X 尺度仍受 binary64 和斜率表示范围限制。
5. 固定seed仅保证同输入/相同实现下重算；`sample_data.dart`中的示例随机源和刻意舍入未调整。
6. 曲线交点现有固定几何容差、样本上限、函数间断点跨越连线等未纳入本数值批次，需单独回归审查。
