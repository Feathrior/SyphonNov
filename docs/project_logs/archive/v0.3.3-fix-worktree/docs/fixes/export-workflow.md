# 页面导出流程补充修复

日期：2026-09-05。来自实现完成后的独立只读审阅，再按主任务授权修复。

## PAGE-01：改页面、DPI 或样式不能重新生成科研数据

原流程是：使用当前结果写出文件 → 保存页面参数 → `updateNodeParams` 触发整图重算。示例输入仍包含随机生成数据，因此成功导出后，屏幕会立即显示另一份数据。仅应用页面或改 DPI 也会触发同样问题。

现在，没有数据输出端口的可视化节点更新参数时，保留历史快照并通知界面重绘，不执行上游数据节点。真实输入/计算节点的参数更新仍保持自动重算。

页面/样式撤销和重做同样保留数据。恢复历史时只比较与执行相关的节点 ID、配置、数据节点参数、连线端点及顺序；忽略终端可视化参数和布局。实际数据或连线不同才清空并重算结果。没有引入执行缓存引擎。

回归用两条独立随机输入分支连接普通图与原理化图，断言改页、改样式、两次撤销和两次重做后，`results`、两个图的输入对象及执行版本号均未改变；随后修改真实数据参数，确认仍执行新计算。

这也是可复现计算的教学反例：控制 seed 只处理随机数来源，用户界面的无关操作还必须避免触发新的实验。对象恒等和执行次数断言比“某次随机值碰巧没变”更可靠。配合阅读 [最小二乘与可复现计算](../learning/03-最小二乘与可复现计算.md)。

## PAGE-02：异常页面参数不得破坏预览或静默导出默认值

属性文本框允许输入范围外数值，例如 `pageWidthMm=2001`、`exportDpi=2401`。旧接入直接在构建图表时构造页面，异常会破坏图表区域。

现在，读已保存/属性参数时严格验证；异常预览临时使用 160 × 100 mm 并显示明确提示。导出弹窗保留实际非法值，要求修正；点击导出会在调用系统保存窗口之前验证。临时预览页面不会作为隐藏替代值写入导出文件或工作流。

回归分别覆盖普通图与原理化图：加载异常文件、打开弹窗、拒绝非法导出、修正并应用、再次从属性更新异常 DPI，均不出现组件异常。另覆盖负数、非数值、NaN 及异常旧像素参数。
