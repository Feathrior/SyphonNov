## 坐标约定

| 图表 | 点、线、面的坐标解释 | 范围规则 |
|---|---|---|
| 散点、数值折线 | `(x,y)` 为原始数据数值 | 表格和所有图元的联合范围 |
| 分类折线 | `x=0,1,…` 对应原始行/分类中心，Y 为数值 | 分类 X 固定为 `[-0.5,n-0.5]`；Y 采用联合范围 |
| 柱状图、箱线图、小提琴图 | `x=0,1,…` 对应实际绘制的分类/组中心，Y 为数值 | 主图范围；超出范围部分裁切 |
| 火山图 | X 为所选 FC 列数值，Y 为 `-log10(p)` | 主图范围；叠加线/点需要提供已经变换后的 Y |
| 热力图 | `(x,y)=(零基列号,零基行号)`；Y 向下增大 | 主图全部格子的范围 |
| 桑基图、网络图 | 没有可供科研数值图元复用的数据坐标轴 | 连接点/线/面时显示“此图无可用数据坐标，点／线／面未绘制”，避免伪造坐标 |
| 所有图的文本输入 | 绘图区九宫格相对定位 | 文本没有数据 X/Y 字段，不参与数据范围计算；仍可独立显示 |

为防止图元覆盖坐标轴标签，叠加数据和文本裁切在其实际绘图区内。数值散点/折线没有额外自动留白，范围端点位于边界；常量轴有显示用扩展。联合范围意味着新增远处参考点会同时缩放主图和其他图元，这是有意选择的行为。

对超出主图范围的参考线，在生成虚线小段之前裁切线段；只在最后调用画布裁切会浪费与屏幕外长度成比例的工作，严重时可使绘图卡住。

## 已知边界

1. 保留全部数据会增加大表格的绘图成本。本次没有增加自动降采样、像素聚合或交互式海量数据性能保证。
2. 数值坐标一致不代表 X/Y 屏幕比例相同；目前没有等比例坐标选项，圆、角度、距离仍需注意轴比例。
3. 小提琴图的核密度估计带宽公式、固定下限与有限采样分辨率没有在本次获得完整统计审定；不可将坐标修复理解为 KDE 已通过验证。
4. 箱线图仍使用最小/最大值作为须；尚未增加 1.5 IQR 须与离群点约定切换。火山图仍使用原先阈值；未增加显著性阈值参数与多重检验流程。
5. 联合范围没有自动剔除离群点。缺失与非有限数不会被画成零，也没有被插值补齐；本次未增加逐行无效数据报告。
6. 图元的 Z 在预制二维图表中仍按 XY 投影；网格显示不能代表三维遮挡关系。
7. 数值列/分类列仍沿用项目的启发式识别规则。含非数值字符串的混合列可能不被热力图、箱线图、小提琴图选为数值列；此类数据应先清洗。极端数值跨越巨大数量级时，浮点表示和屏幕分辨率本身也构成限制。
