# 从拟合失败认识条件数、QR 与可复现计算

先修：[[01-表达式与误差传播]]，以及向量内积、矩阵乘法和多项式。学习目标是区分“方程有解”“算法稳定”“输出表示适合计算”这三个问题。

## 1. 原实现解的方程

拟合 $p(x)=c_0+c_1x+\cdots+c_dx^d$，给定 n 个观测，构建设计矩阵

$$A=\begin{bmatrix}1&x_1&\cdots&x_1^d\\\vdots&\vdots&&\vdots\\1&x_n&\cdots&x_n^d\end{bmatrix},\quad
\min_c\|Ac-y\|_2^2.$$

把目标函数对 c 求导可得 $2A^T(Ac-y)=0$，即正规方程 $A^TAc=A^Ty$。旧代码直接构造它，然后做高斯消元。

这个推导在数学上正确，但计算路径可能不稳定。满列秩时，$A^TA$ 的特征值是 A 的奇异值平方，因此

$$\kappa_2(A^TA)=\frac{\sigma_{\max}(A)^2}{\sigma_{\min}(A)^2}=\kappa_2(A)^2.$$

若 A 的条件数为 $10^8$，正规矩阵约为 $10^{16}$，已与 binary64 的精度尺度相当。这不是说每一组数据都必然丢掉全部有效数字，而是对输入/舍入扰动的放大风险很高。

## 2. 一个奇异反例与一个病态反例

**奇异：** x 全等于 1，y 为 1,2,3，拟合直线 $a+bx$。矩阵的两列完全相同。最优预测在 x=1 处为均值 2，但只约束 $a+b=2$，没有唯一的 a、b。旧求解器遇小主元时直接跳过，最后还可能把某个系数写成 0，制造“已经求出唯一模型”的假象。现在明确拒绝秩不足。

**尺度病态：** 令 $x_i=10^9+i$，$i=0,\ldots,10$，并令

$$y_i=2+3i+\tfrac12i^2.$$

这些观测十分规则，但原始基底 $1,x,x^2$ 的大小极不相称，二、三列也高度相关。新回归测试要求在全部采样点和中间点 $x=10^9+4.5$ 都获得准确预测，后者正确值是 25.625。测试不是只检查系数的外观。

另一个独立尺度反例是 $A=\mathrm{diag}(10^{-20},2\times10^{-20})$、$b=(10^{-20},4\times10^{-20})^T$。精确解就是 (1,2)，旧绝对主元阈值 $10^{-12}$ 会把正常小量矩阵当成零。独立线性求解器现在用相对于行尺度的主元比较，并在无法可靠求解时抛出错误。

## 3. 先改善坐标，再选择计算路径

本次把 X 改写成

$$t=\frac{x-m}{s},\quad m=\frac{x_{\min}+x_{\max}}2,\quad s=\max_i|x_i-m|.$$

实现中用 $x_{\min}/2+x_{\max}/2$ 计算中心，减少端点先相加导致溢出的机会。非退化区间中 $t\in[-1,1]$，再用基底 $1,t,\ldots,t^d$ 拟合。Y 也先按最大绝对值缩放，最终把系数还原。

这改善量级，却没有神奇地消除所有病态性：高阶单项式基底仍可能高度相关，聚集的节点也可能产生数值秩不足。不得把“缩放后没有报错”等同于“系数已高度可信”。

## 4. 为什么 Householder QR 避免正规方程

满列秩时写 $A=QR$，Q 的列正交，R 为上三角。利用正交变换保持二范数，可将最小二乘转为三角方程

$$Rc=Q^Ty.$$

程序用 Householder 反射逐列消元。对列向量 v，选择适当符号构造 u，使

$$H=I-2\frac{uu^T}{u^Tu}$$

把当前列主元下面的元素变为零。相同反射同时作用于右端 y，最后回代。符号选为避免 `v[0]` 与其范数相减时发生严重抵消。无需显式构造完整 Q，也无需形成 $A^TA$。算法依据可对照 [LAPACK 的 QR 最小二乘说明](https://netlib.org/lapack/lug/node40.html)。

本次是面向当前低阶节点的自包含实现，使用尺度相关的秩阈值；没有列主元 QR、SVD、条件数估计或系数置信区间。LAPACK 对 [满秩与秩亏最小二乘](https://www.netlib.org/lapack/lug/node27.html) 的区分，可作为后续升级方向。

## 5. 正确系数也可能不适合直接代入

为单独展示抵消，给上述大偏移例子另取局部坐标 $u=x-10^9=i$，表达式只需 $2+3u+0.5u^2$。展开到 x 后，常数项约 $5\times10^{17}$，一次项约 $-10^9$，二次项为 0.5。在 $x\approx10^9$ 处，这几项都是巨大量，互相抵消后才得到几十。

即便用 Horner 法减少乘法次数，也不能使这个表示自动变得良态。`PolynomialFitResult` 因此保留中心、尺度及缩放系数，绘图在该基底求值。原 x 基底的 `c0,c1,...` 仍输出到参数表以保持兼容，但这张表属于另一种可能病态的表示；不要从它显示的位数推断精度，也不要在大偏移场景里优先用它重算曲线。

这里有一个重要区分：系数可能敏感，而区间内预测仍较稳定。外推又是另一个问题，不能从区间内测试通过推断远处预测可信。

## 6. 模型选择和统计含义也需要明确

原节点的“线性拟合”默认仍读取多项式阶数 2，标签和实际模型不一致。现在选择线性时固定一阶，只有多项式模式读取阶数；两个不同 X 已足以确定一条直线。

指数拟合采用 $\log y=\log a+bx$ 的线性回归。它最小化的是 **对数响应的残差平方和**，不是原始 Y 的残差平方和。以前 y≤0 的点被悄悄删除；现在整个输入被拒绝，避免使用者不知道模型只拟合了部分样本。输出 R² 对应对数空间；常数响应的分母为零，数学上未定义，因此输出空值，而不是伪报好坏。

### 交叉审阅反例：输入和答案都正常，中间步骤却溢出

取 $x=[1000,1001,1002]$、$y=[1,e,e^2]$，准确模型为

$$y=\exp(x-1000).$$

若先转换成 $a\exp(bx)$，则 $a=\exp(-1000)$、$b=1$。binary64 中前者下溢成零，而 $\exp(1000)$ 上溢成无穷大，最后计算 $0\times\infty$ 得到 NaN。输入 Y 仅约 1 到 7.39，不能把这归因于“响应本来就太大”。问题在于拆开了本来能够互相抵消的指数。

中心化对数模型写成

$$\log y=\alpha_c+b(x-c),\qquad
y=\exp\bigl(\alpha_c+b(x-c)\bigr).$$

取中心 $c=1001$，则 $\alpha_c=1$。预测过程中指数只在 $[0,2]$ 内变化。程序现在保留并输出 `x_center`、`log_y_at_center`、`b`；原点系数 `a` 如果不可表示，则标为带说明的空值，不能输出零诱导用户认为整个模型恒为零。

这是**表达式重组改善数值稳定性**的例子：精确算术中 $e^u e^v=e^{u+v}$，有限精度计算中两条路径却可能一条成功、一条失败。它并不让任意外推都可计算；若最终 $\exp(\alpha_c+b(x-c))$ 本身超出可表示范围，程序明确报错。

## 7. 随机抽样为什么也是数值实验的一部分

同一组参数重算时，如果每次随机抽取不同数据，比较算法改动后的误差就混入了样本变化。现在抽样节点增加整数 `seed`，默认 0；每次以同一 seed 初始化随机数发生器，得到同一组行索引。各列使用同一组索引，抽样后恢复原行序。

同一 seed 的复现承诺限于同一输入顺序及相同软件/运行时实现，不能承诺 Dart 的随机算法永远跨版本不变。严谨实验还应保存原数据、工作流、seed、项目版本、运行时版本。示例数据预设仍使用未固定种子的全局随机源，不能当成固定实验数据；本批没有改写那个生成器。

## 练习

**A.** x=1,1,1，y=1,2,3。可以得到唯一的最优预测值，却得不到唯一系数，矛盾吗？

<details><summary>答案与解释</summary>

不矛盾。最优常数预测是均值 2，但所有满足 $a+b=2$ 的直线在观测位置都给出同一预测。模型参数的可辨识性比观测位置预测的唯一性要求更强。

</details>

**B.** 若 $p(t)=2+3t+0.5t^2$，$t=x-10^9$，手工展开成 x 的多项式，估计在 x=10⁹ 时需要抵消多少位。

<details><summary>答案与解释</summary>

$c_2=0.5$，$c_1=3-10^9$，$c_0=2-3\times10^9+0.5\times10^{18}$。要从约 $10^{18}$ 量级的项还原个位数，涉及约 18 位十进制尺度，而 binary64 只有约 16 位十进制精度。继续使用局部基底更合适。

</details>

**C.** 比较两个平滑窗口大小时，为什么应该固定随机抽样 seed？是否一个 seed 的结果就足以判断算法普遍更好？

<details><summary>答案与解释</summary>

固定 seed 让两个设置面对相同样本，隔离窗口改变的影响。一个 seed 只提供一次样本上的比较；评估普遍效果需预先确定多个 seed 或独立数据集，报告误差的分布，而不是挑选最有利的样本。

</details>

**D.** 在上例中改用中心 $c=1002$，中心化截距 $\alpha_c$ 应是多少？预测 $x=1000.5$，是否需要先计算 $a$？

<details><summary>答案与解释</summary>

$\alpha_c=2$，所以 $\alpha_c+b(x-c)=2+(1000.5-1002)=0.5$，预测为 $e^{0.5}$。不需要计算原点系数 $a=e^{-1000}$。改变中心只改变参数表示，不改变模型函数。

</details>
