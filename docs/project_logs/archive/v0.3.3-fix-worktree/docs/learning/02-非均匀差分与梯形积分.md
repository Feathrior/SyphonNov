# 从三点反例推导非均匀差分与梯形积分

先修：[[01-表达式与误差传播]]。本篇只处理函数数据 $y=f(x)$，不是任意参数曲线。修复后的微积分节点要求有限坐标、严格递增的 X；不会擅自排序或用一个小数替代零间隔。

## 1. 原算法为什么在三个点上就失败

取 $f(x)=x^2$，给出点 $(0,0),(1,1),(3,9)$。要在 x=1 求导，精确值是 2。原实现算两侧点连线斜率：

$$\frac{f(3)-f(0)}{3-0}=3.$$

这条割线跨越的中点是 1.5，不是 1。均匀网格上熟悉的中心差分不能简单套到不对称的三点上。

设左步长 $h_s=x_i-x_{i-1}$，右步长 $h_d=x_{i+1}-x_i$，分别为 1 和 2。左右割线斜率是 1 和 4。修复后的值是

$$\frac{h_d}{h_s+h_d}\frac{f_i-f_{i-1}}{h_s}
+\frac{h_s}{h_s+h_d}\frac{f_{i+1}-f_i}{h_d}
=\frac23\cdot1+\frac13\cdot4=2.$$

较长的一侧割线获得较小权重，这源于消去二阶导数项，不是经验调参。

## 2. 从 Taylor 展开推导权重

在 $x_i$ 附近，假设 f 有足够连续导数：

$$f_{i-1}=f_i-h_sf'_i+\frac{h_s^2}{2}f''_i-\frac{h_s^3}{6}f'''_i+\cdots,$$

$$f_{i+1}=f_i+h_df'_i+\frac{h_d^2}{2}f''_i+\frac{h_d^3}{6}f'''_i+\cdots.$$

希望 $D_i=a f_{i-1}+b f_i+c f_{i+1}$ 满足常数导数为 0、线性函数导数正确、二阶项消失，于是

$$a+b+c=0,\quad-ah_s+ch_d=1,\quad ah_s^2+ch_d^2=0.$$

解得

$$a=-\frac{h_d}{h_s(h_s+h_d)},\quad
b=\frac{h_d-h_s}{h_sh_d},\quad
c=\frac{h_s}{h_d(h_s+h_d)}.$$

整理后就是程序中的两侧斜率加权公式。三阶项系数是 $h_sh_d/6$；当网格同步缩小且函数光滑时，内点误差为二阶量级。均匀时 $h_s=h_d=h$，中间系数 b=0，恢复 $(f_{i+1}-f_{i-1})/(2h)$。官方实现背景可对照 [NumPy gradient 的非均匀网格推导](https://numpy.org/doc/2.1/reference/generated/numpy.gradient.html)。

## 3. 为什么端点和重复 X 必须单独说

本次仍保留端点的一阶单边差分。以上反例输出导数是 `[1,2,4]`，端点真值分别是 0、6，所以端点误差确实存在；修复不宣称整条导数曲线都具有二阶精度。只有两个点时，两端都返回同一割线斜率。

单点不能确定斜率，现在给出明确错误；空点列输出空列。重复 X 如 `(0,1),(0,2)` 甚至不能构成这个位置的单值函数。原程序用 $10^{-9}$ 替代分母 0，会制造斜率 $10^9$，并把数据问题伪装成极陡曲线。现在拒绝重复 X，要求使用者先决定重复观测是取均值、保留某次测量，还是另建参数曲线模型。

注意：$10^{-12}$ 的**真实正步长**仍然有效，不应因为小于固定阈值就被视为重复。这就是数值阈值必须考虑问题尺度的例子。但如果输入在 binary64 中已经舍入成相同的 X，后续算法无法恢复丢失信息。

## 4. 梯形积分的依据与精确性

在相邻点间用线性插值

$$p_i(x)=y_{i-1}+\frac{y_i-y_{i-1}}{h_i}(x-x_{i-1}),\quad h_i=x_i-x_{i-1},$$

积分得到

$$T_i=\int_{x_{i-1}}^{x_i}p_i(x)\,dx=\frac{h_i}{2}(y_{i-1}+y_i).$$

累积积分输出 $I_0=0$，$I_k=\sum_{i=1}^{k}T_i$。起点 0 是积分常数的选择，不是说函数在起点的真实原函数值必为 0。

对 $f(x)=2x+1$，取 x=0,1,3，得到面积 2、10，累积 `[0,2,12]`，与 $x^2+x$ 相符。梯形法对一次多项式精确，非均匀步长也不影响这个性质。

对 $f(x)=x^2$，在 [0,1] 分成 n 个等距小区间：

$$T_n=\frac13+\frac1{6n^2}.$$

因此 n 加倍后误差缩小到四分之一。测试检查 n=8 与 n=16 的误差比，而不是仅看某一组答案“差不多”。这验证的是收敛阶，能发现看似平滑却使用错误算法的实现。

一般对 $f\in C^2$，单区间梯形误差满足

$$T_i-\int_{x_{i-1}}^{x_i}f(x)\,dx=\frac{h_i^3}{12}f''(\xi_i).$$

若 $|f''|\le M$，全局误差可界为 $\frac{M}{12}\sum h_i^3\le\frac{M(b-a)}{12}h_{\max}^2$。这也说明只在局部密集采样、留下一个大间隔，不足以保证整体积分精度。

## 5. 面积累加也会损失小量

浮点数间距随数量级改变。将许多很小面积逐个加入一个很大累计值，小面积可能无法改变当前表示。修复使用 Kahan 补偿累加，额外记录上次加法损失的低位，在下一次累加时补偿。它减少求和舍入误差，却不能修复梯形近似误差，也不能挽回输入先前被清零的值。

程序还把平均高度写成 `y0/2 + y1/2`，避免两个很大同号有限数先相加就溢出。极端微小的次正规数可能因除 2 下溢，极端跨度也可能使面积溢出；本批不提供任意精度保证。

## 练习

**A.** 在 x=1,2,4 上采样 $f(x)=x^2$，求中间点的新旧差分值。

<details><summary>答案与解释</summary>

旧割线值 $(16-1)/(4-1)=5$。新值 $(2/3)(4-1)+(1/3)(16-4)/2=4$，等于 $f'(2)$。

</details>

**B.** 两点 `(0,1),(0,1)` 的 Y 一样，可否把差分定义成 0？

<details><summary>答案与解释</summary>

不能从这两点推出导数为 0，它们只给出同一位置的重复值。无穷多条不同斜率的光滑曲线都可经过这个点。去重后还需另一不同 X 的观测。

</details>

**C.** 用梯形法积分 $x^2$，n=10 时误差为多少？要把误差缩小为原来的 1/100，n 至少改为多少？

<details><summary>答案与解释</summary>

误差为 $1/(6\times100)=1/600$。因为误差与 $n^{-2}$ 成正比，n 增大 10 倍到 100；这是假设舍入误差可以忽略时的结论。

</details>
