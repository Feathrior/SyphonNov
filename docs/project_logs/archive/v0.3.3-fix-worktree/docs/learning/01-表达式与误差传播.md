# 从错误曲线认识表达式语义与误差传播

这篇从项目中的两个真实问题出发：`2*x^2` 曾被理解成 `(2*x)^2`；数值节点曾先保留六位小数，再把这个结果传给下一个节点。前者是数学对象被改写，后者是输入被扰动。它们必须分开诊断。

学习顺序：本篇 → [[02-非均匀差分与梯形积分]] → [[03-最小二乘与可复现计算]]。

## 1. 在讨论精度前，先确认算的是什么

数学约定下，`2*x^2` 的运算树是“先计算 x 的平方，再乘 2”。原程序把幂与乘除放在同一个循环中，按从左到右计算，所以在 x=3 时给出 36，而正确值是 18。这是可用整数算术完全确认的反例，与机器精度无关。

同一类错误还有结合顺序和负号：

| 输入 | 修复后的含义 | 值 |
|---|---|---:|
| `2^3^2` | `2^(3^2)` | 512 |
| `(2^3)^2` | 括号明确指定先算左边 | 64 |
| `-3^2` | `-(3^2)` | -9 |
| `(-3)^2` | 负数整体平方 | 9 |
| `2^-3` | `2^(-3)` | 0.125 |

修复使用分层语法：加减、乘除、一元正负、幂、原子表达式。幂的右操作数允许一元正负，并可继续解析幂，所以既能右结合，又支持负指数。`^` 与 `**` 都表示幂。函数、变量不区分大小写；科学记数法 `1e-7` 的 `e-7` 必须整体属于数字，不能把减号误认成表达式的减法。

这里采用的是本项目明确规定的语义；其他软件可能采用不同约定。跨工具迁移公式时，优先写清括号。

“只读懂前半句”同样危险。原来的 `x garbage` 可能被接受为 x，缺失右括号也可能通过。现在必须消费完整输入、配平括号；`2x` 不支持隐式乘法，应写 `2*x`。保留旧有 `pi(x)` 写法作为 `pi*x` 的兼容形式，但推荐显式乘号。

## 2. 固定小数位不是有效数字

设真实计算值为 z，旧节点输出的是

$$Q_6(z)=10^{-6}\operatorname{round}(10^6z).$$

忽略二进制边界细节，这种十进制量化的绝对误差最多约 $0.5\times10^{-6}$，但其相对误差界为

$$\frac{|Q_6(z)-z|}{|z|}\lesssim\frac{0.5\times10^{-6}}{|z|}.$$

当 z 很小时，这个界没有实用价值。真实反例：$z=10^{-7}$ 被改成 0，绝对误差只有 $10^{-7}$，相对误差却是 100%。把保留位数从 6 改成 12 只能移动出错尺度，不能从设计上解决问题。

更隐蔽的是 X 也被舍入。函数节点在 $[0,10^{-7}]$ 上取三个点时，原本是

$$x=(0,5\times10^{-8},10^{-7}),$$

六位小数会把三点全部变成 0，后续差分不再有有效网格。修复后，各节点直接传递 `double`，只在界面显示时控制文本精度。导入/转换、填补、归一化、公式、微积分及拟合输出都遵循这个边界。

## 3. 为什么去掉舍入后还不能说“绝对精确”

`double` 是有限精度的二进制浮点数。以常见正规范围内的舍入模型表示，单次基本运算可写为

$$\mathrm{fl}(a\circ b)=(a\circ b)(1+\delta),\qquad |\delta|\le u,$$

其中 binary64 的单位舍入误差 $u=2^{-53}\approx1.11\times10^{-16}$。这不包含溢出、下溢和非有限输入，也不能直接替代整个算法的误差分析。有关表示与舍入的背景可读 [Goldberg 的浮点算术论文](https://docs.oracle.com/cd/E19957-01/806-3568/ncg_goldberg.html)。

需要区分三类误差：

1. **测量误差**：输入观测本身不准确，换算法不能恢复未知真值。
2. **离散化误差**：用差分代替导数、梯形代替面积所引入的误差。
3. **舍入误差**：运算在有限精度里发生；旧程序还额外叠加了十进制量化误差。

解析器的错误应单列为“实现错误”，不能拿误差容限掩盖。

## 4. 误差如何被下游放大

假设真实函数值 $y_i$ 被改成 $y_i+e_i$，且 $|e_i|\le\varepsilon$。前向差分变成

$$\frac{(y_{i+1}+e_{i+1})-(y_i+e_i)}h
=\frac{y_{i+1}-y_i}h+\frac{e_{i+1}-e_i}h.$$

因此附加误差不超过 $2\varepsilon/|h|$。若 $\varepsilon=5\times10^{-7}$，$h=10^{-4}$，仅固定小数位带来的误差界就达到 0.01。加密网格会减小离散化误差，却同时增大这项误差。

中心差分通常有 $O(h^2)$ 的截断误差。粗略平衡 $C_1h^2+C_2u/h$，可得最优步长量级 $h\sim u^{1/3}$；常数取决于函数尺度和导数，不能机械地把 $u^{1/3}$ 当作通用步长。这个结论解释了“采样点越多越准”为什么不成立。

## 5. 本项目如何验证

- `test/formula_parser_test.dart` 使用精确可算的数值检查语义，并逐个拒绝截断输入、缺失括号、坏科学记数法。
- `test/numerical_pipeline_test.dart` 让 $10^{-7}x$ 沿函数 → 公式/求导/积分传播，验证坐标 $5\times10^{-8}$、导数 $10^{-7}$、积分 $5\times10^{-22}$ 没被清零。
- 对整数语义用精确相等；对浮点计算用结合结果量级的绝对容差。不要对所有结果统一设 `1e-6`，否则“正确值是 $10^{-14}$，错误值是 0”也会通过。

## 练习

**A.** 按本项目语义计算 `-2^2^3`、`(-2)^2^3`、`2^-2^2`。

<details><summary>答案与解释</summary>

分别为 $-(2^{(2^3)})=-256$、$(-2)^{(2^3)}=256$、$2^{-(2^2)}=1/16$。先确定括号结构，再计算，不要根据屏幕上运算符出现的先后顺序猜。

</details>

**B.** 将 $x=0.123456789$ 和 $x=1.23456789\times10^{-9}$ 都保留六位小数，它们的相对误差是否接近？

<details><summary>答案与解释</summary>

第一个变为 0.123457，绝对误差约 $2.11\times10^{-7}$，相对误差约 $1.71\times10^{-6}$。第二个变成 0，相对误差 1。固定小数位控制的是一种绝对尺度，而不是相对精度。

</details>

**C.** 测量误差界固定为 $10^{-5}$。把差分步长从 $10^{-2}$ 改成 $10^{-4}$，由测量误差产生的最坏误差界如何变化？

<details><summary>答案与解释</summary>

$2\varepsilon/h$ 从 0.002 增至 0.2，增加 100 倍。要判断总误差，仍须合并截断误差；不能仅凭这个界断言某次观测一定更差。

</details>

## 尚未解决的边界

函数的定义域错误仍以 NaN 告知调用层；函数曲线会过滤非有限采样点，跨间断点连线的展示策略尚需进一步审查。示例数据生成器的刻意舍入未在此批移除，它不代表对实测数据的精度保证。
