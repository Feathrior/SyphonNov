# 坐标映射与图形可信度

本笔记来自 SyphonNov 的实际修复。先掌握线性插值、函数图像、浮点数的基本概念即可阅读。目标是能区分**数据算错、坐标画错、刻度显示错**这三种不同错误，并用反例检查自己的数值程序。

对应工程记录：[绘图修复](../fixes/plotting.md)。可运行证据：`test/chart_coordinates_test.dart`。

## 1. 数据坐标怎样变成屏幕位置

设数据横坐标范围为 $[x_{\min},x_{\max}]$，绘图区从像素 $L$ 延伸到 $R$。需要两个端点条件：

$$p_x(x_{\min})=L,\qquad p_x(x_{\max})=R.$$

要求中间位置按线性比例变化，即设 $p_x(x)=ax+b$。将端点代入并相减，得到

$$a=\frac{R-L}{x_{\max}-x_{\min}},\quad b=L-ax_{\min}.$$

所以仿射映射（affine map）为

$$\boxed{p_x(x)=L+\frac{x-x_{\min}}{x_{\max}-x_{\min}}(R-L)}.$$

屏幕通常向下增加像素 Y，而数学纵轴向上增加。若顶部像素为 $T$，底部为 $B$，则

$$\boxed{p_y(y)=B-\frac{y-y_{\min}}{y_{\max}-y_{\min}}(B-T)}.$$

分式是无量纲的归一化坐标（normalized coordinate）。它把数据范围变成 $[0,1]$，之后才乘以像素长度。

### 实际反例：看似叠加，实际使用了两把尺子

表格 X 范围为 $[0,100]$。参考曲线只覆盖 $[25,75]$。如果各自归一化，那么同一个数值 $x=25$ 会得到

$$u_{\text{table}}=\frac{25-0}{100-0}=0.25,\qquad
u_{\text{overlay}}=\frac{25-25}{75-25}=0.$$

两者相差绘图区宽度的四分之一。对宽 $335$ 像素的图，这就是 $83.75$ 像素，不是抗锯齿造成的细微差别。拟合线、参考点、误差区域都可能因此误导读者。

**修复原则：先确定共同坐标系，再画每个对象。** 本次散点/数值折线取所有数据与图元的联合范围；其他已有数值轴图表沿用主图范围。无论采用哪种规则，主图和叠加层必须共享完全相同的映射。

### 一个可用于测试的不变量

对任意两个输入对象，如果它们都含同一数据点 $(x,y)$，那么它们的像素中心必须相同。这是**同值同位不变量**，比“能够渲染且不报错”更强。

还可以检查仿射映射保留相对距离比：

$$\frac{p_x(x_2)-p_x(x_1)}{p_x(x_3)-p_x(x_1)}
=\frac{x_2-x_1}{x_3-x_1},\qquad x_3\ne x_1.$$

## 2. 非均匀采样不能画成等距分类

考虑三个观测点

$$ (0,0),\ (1,1),\ (10,0). $$

真实横坐标中，相邻间距分别为 $1$ 和 $9$。峰值位置应是横向跨度的 $1/10$。原程序把数值 X 仅作为标签，使用行号 $0,1,2$ 排列，峰值却出现在中间。

这相当于先做了一个不正确的横轴变换，再绘图。原来的分段线性插值（piecewise linear interpolation）是

$$s(x)=\begin{cases}
x,&0\le x\le1,\\
\dfrac{10-x}{9},&1\le x\le10.
\end{cases}$$

所以 $s(5)=5/9$。误画成等距时，读者可能误认为峰值就在 $x=5$，在那里读出 $1$。

这与数值分析中的一个基本要求相同：离散数据不仅包含函数值 $y_i$，还包含节点位置 $x_i$。使用非均匀节点时，差商

$$\frac{y_{i+1}-y_i}{x_{i+1}-x_i}$$

和梯形积分

$$\sum_i \frac{y_i+y_{i+1}}{2}(x_{i+1}-x_i)$$

都必须使用真实间距。画图时忽略间距，与求导或积分时擅自把 $h_i$ 改成常数具有相同的信息丢失问题。

类别数据另当别论：A、B、C 没有数值距离。它们可以等距排列，但坐标语义要明确。本次采用零基序号 $0,1,2$ 对应类别中心，数值图元按这个序号定位。

## 3. 为什么 `max(范围, 1e-9)` 不稳健

旧实现担心分母为零，于是写成

$$u=\frac{x-x_{\min}}{\max(x_{\max}-x_{\min},10^{-9})}.$$

对范围 $[0,2\times10^{-12}]$ 的数据，中点 $10^{-12}$ 的正确归一化坐标应为 $1/2$。旧实现得到

$$u=\frac{10^{-12}}{10^{-9}}=10^{-3}.$$

中点被挤到左边缘附近。代码没有报错，但图像已经错误。

### 量纲分析（dimensional analysis）

假设 X 的单位是米，$x_{\max}-x_{\min}$ 也具有米的量纲。裸常数 `1e-9` 在这里就被隐式解释成“十亿分之一米”。如果把输入改用纳米，代码却仍使用 `1e-9`，其物理含义就改变了。

对于正数 $c$，相同数据统一换单位后，图像应该不变：

$$\frac{cx-cx_{\min}}{cx_{\max}-cx_{\min}}
=\frac{x-x_{\min}}{x_{\max}-x_{\min}}.$$

这称为尺度不变性（scale invariance），非常适合做**变形测试**（metamorphic testing）：同一组数据分别乘以 $1$、$10^{-12}$，比较实际绘出的像素坐标，不必为每个点另写期望答案。

### 零跨度和很小的非零跨度是两回事

- $x_{\max}>x_{\min}$：只要差别可由浮点数表示，它就是真实非零范围，不能因为绝对值小而当作零。
- $x_{\max}=x_{\min}$：数据确实没有横向跨度，可以给显示范围加相对留白；原始数据不变。
- 两个不同实数在转成 `double` 后相同：信息已在前一步丢失，绘图无法恢复，应检查数据读入和数值表示。

这里并不是说数值程序永远不能使用容差。比较近似计算结果时，绝对与相对容差有合理用途；但需要先明确误差模型、量纲和目的。防止除零与判定“近似相等”不是同一个问题。

### 浮点加法甚至可能不再前进

原刻度循环用 `v += step`。当 $v$ 很大、步长小于该位置的浮点间距（ULP, unit in the last place）时，舍入后的 `v + step` 可能仍等于 `v`，循环永远无法退出。

修复采用有上限的整数计数循环，避免“能够多次相加”被误认为“每次必然严格变大”。当合适的漂亮刻度难以表达时，回退到端点也比卡住可靠。

### 调试中真实遇到的“测试过严”反例

验证热力图叠加位置时，手算结果为约 $365.45454545$ 像素；从底层路径读出的数值为 $365.45455933$ 像素，相差约 $1.39\times10^{-5}$ 像素。坐标算法没有错，差异来自绘图路径内部使用 float32 存储。

如果测试要求 $10^{-8}$ 像素误差，就超过了这个表示层能保证的精度。float32 的相对机器精度约为 $2^{-23}\approx1.19\times10^{-7}$；乘以数百像素的尺度，便可估计表示误差的量级。本次几何断言采用 $10^{-4}$ **像素**容差，明显小于一个像素，并覆盖路径存取误差。

这与前面的错误 epsilon 有三个区别：容差的单位明确是像素，大小依据已知表示误差选择，它只用于比较结果，不修改绘图映射的分母。合理的数值验证既不能把明显错误当作正确，也不能要求超出底层数值表示能力的精度。

## 4. 截断和显示精度也是科学问题

### 第 5001 个点可能恰好最重要

设前 5000 行是 $(0,0)$，第 5001 行是 $(100,100)$。旧散点图只画前 5000 行，异常值和整个数据范围一起消失。若数据按时间、浓度或温度排序，截取前 N 行还是一种有方向的选择偏差（selection bias）。

因此性能优化不能悄悄改变研究者看到的样本集合。本次完整绘制有效数据；如果要抽样，应通过明确的抽样步骤，并保存方法、样本量和随机种子。

### 正确像素也需要正确刻度文字

数值 $10^{-12}$ 和 $2\times10^{-12}$ 若均用十位小数显示，会都变成 `0.0000000000`。即使点位正确，这张图也失去了可读的数量级。

计算值、图元坐标、刻度字符串应分别处理。绘图中的格式化用于读数；不能倒过来用格式化后的字符串代替下游计算值。本次使用科学记数法保留小量级刻度的区分。

热力图还有同样的归一化问题：

$$c(v)=\frac{v-v_{\min}}{v_{\max}-v_{\min}}.$$

固定 epsilon 会把微小但有意义的变化全部挤成同一种颜色。若所有值确实相同，色带中点是一种显示约定，此时图例仍要说明它们对应相同数值。

## 5. 统一坐标之后仍要问什么

横向和纵向像素比例通常不同。即使数据是单位圆 $x^2+y^2=1$，若每个 X 单位占 100 像素、每个 Y 单位只占 50 像素，屏幕上仍然是椭圆。仿射坐标一致保证点线关系，不自动保证角度和距离。

读取科学图形前还应明确：X/Y 单位、线性或对数变换、样本是否缺失、连线是否代表插值、类别顺序、箱线须的定义、密度估计带宽。这里每一项都是模型或显示约定，不能由“图看起来平滑”推出正确性。

本次没有将这些尚未完整审定的统计和几何约定宣布为已修复；见工程记录的已知边界。

### 视觉验证中的几何：旋转标签需要多少空间

最后检查实际 PNG/PDF 时，热力图的完整列名被页面底边截断。字号没有错，问题在于固定留出 70 像素，却没有计算斜放文字所占的高度。

将宽 $w$、高 $h$ 的文字矩形旋转 $\theta$，旋转后轴对齐包围框的尺寸为

$$W=|w\cos\theta|+|h\sin\theta|,\qquad
H=|w\sin\theta|+|h\cos\theta|.$$

可从矩形四个顶点的旋转坐标分别取最大、最小值推出。对于长单行标签，纵向占位由 $w\sin\theta$ 主导，不能只根据字号估算。修复先用同一字体测量完整文字，再计算旋转后的占位；增加页面边距，而不是删除标签后半段。

这个例子也说明，自动测试只检查“生成了一个文件”不够。数据正确、坐标正确、文字完整可读是连续但不同的验证环节。测试字体 Ahem 的黑方块还需要与真实布局缺陷分开识别，不能把测试替身误当作交付成品。

## 练习与自检

### 练习 1：独立计算一个像素点

绘图区 $L=45,R=380,T=30,B=260$，两个数据轴范围均为 $[0,100]$。求 $(25,50)$ 的像素位置。

> [!answer]- 展开答案
> $p_x=45+0.25\times335=128.75$，$p_y=260-0.5\times230=145$。所以位置为 $(128.75,145)$。这是实际回归测试使用的手算证据。

### 练习 2：联合范围的可见影响

主表格原范围为 $[0,10]\times[0,10]$，新增参考点 $(20,20)$。共同取联合范围后，原点 $(10,10)$ 应画在什么位置？为什么不能让参考点单独 fit？

> [!answer]- 展开答案
> 联合范围为 $[0,20]\times[0,20]$，$(10,10)$ 在绘图区中心；它不再处于右上角。单独 fit 会把两个图层的数值刻度割裂，无法比较同一个 X/Y。

### 练习 3：非均匀节点的积分

仍用 $(0,0),(1,1),(10,0)$。按真实节点做复合梯形积分是多少？如果把两个间距都误当成 1，结果又是多少？

> [!answer]- 展开答案
> 正确为 $\tfrac12(0+1)\times1+\tfrac12(1+0)\times9=5$。误用单位间距得到 $1$。这同时改变了数值和单位，不能用“点数相同”来解释其合理性。

### 练习 4：设计一个比“不抛异常”更强的测试

如何不依赖截图的人工观察，检查单位变换没有破坏图形？

> [!answer]- 展开答案
> 取若干非共点坐标，运行一次绘图并记录绘制中心；把 X/Y 数据都乘以 $10^{-12}$ 再绘制。比较对应像素位置，在像素浮点容差内应相同；同时验证刻度字符串仍能区分不同刻度。几何正确与文字可读是两个断言。

### 练习 5：为什么缺失行应该断线

观测为 $(0,0),(1,1),(2,\text{missing}),(3,3),(4,4)$。直接删除缺失行再连线，向读者隐含了什么？什么情况下可以有意这样做？

> [!answer]- 展开答案
> 它隐含了从 $(1,1)$ 到 $(3,3)$ 的连续线性插值，掩盖了中间没有观测值的事实。只有当插值模型是明确选择、且图例/方法说明这种处理时，跨缺口连线才是可审查的决定。本次默认断开路径，不把缺失值补成零。
