## 5. 建议下一步的顺序

1. **先补正确性闭环**：处理原理化有效小尺度轴、6000 点截断和注释锚点；将色标范围模式明确区分自动/固定；分布柱明确计数/频率/密度语义。同步修正文案，避免描述与实现不一致。
2. **再补通用实验绘图**：误差条及置信带数据模型、明确误差定义；原生 log/date 轴与 equal-aspect 约束；多系列自动图例、可配置轴标签/范围。先选有真实数据的端到端用例，避免只增加空端口。
3. **补论文成图流程**：多面板、共享轴/色标/图例、数据锚定注释、数学文本、按请求字体导出与批量任务。以同一论文图在预览、PNG、SVG、PDF 和外部阅读器中一致为验收目标。
