## 5. 容易误用、但应归为能力边界的两件事

**“线性插值”当前指行号，不是物理横坐标。** 对 `x=[0,1,10]`、`y=[0,null,10]`，界面参数 `fillMissing=interp` 实测填入 `5`。这是两个行号端点 0 和 2 的中点；若目标是对物理 x 的线性函数插值，应为 `1`。代码没有选择自变量列的接口，且边缘空值采用均值，见 [exec.dart](../../lib/models/exec.dart) 第 443–459 行。等间距索引插值本身有效，但需要在界面说明；面向非均匀采样应提供独立的 X 感知插值，并选择如何处理重复 X、外推与缺口。

**“平滑”当前指按观测索引的等权移动平均。** `window` 是半径 w，内部点最多使用 `2w+1` 个样本，边界窗口缩短；代码不看 X 间距。非均匀采样时它不是固定物理宽度的卷积。平滑还会引入偏差、改变峰高和端点，不是“让测量更真实”的无条件操作；输出最好保留方法与窗口信息。是否采用保峰方法、局部多项式或平滑样条，需先明确数据和任务。

## 6. 从这些反例学习：对象、尺度与不确定度

### 6.1 删除坏点会改变数学对象

`1/x` 在 `[-1,0)` 与 `(0,1]` 上分别连续，但在整个 `[-1,1]` 上不连续。介值定理要求函数在闭区间上连续；仅知道端点值异号不能推断它有零点。

把中间未定义点删掉，再用两个剩余点连线，得到的是另一条函数 `y=x`。求交器对这条伪造的线算出 `(0,0)` 并不神秘：上游已经把待求问题换掉了。因此，需要把定义域、分段和缺失位置作为流水线信息保留，而不能只留下所有“看起来有效”的有限点。增加采样数可能让伪线变得更陡，却不能自动证明跨过奇点的连接合法。

### 6.2 单位缩放是比“多测几个数”更强的检查

两条线段的方向为 r、s，求交分母是二维行列式

$$d=r_xs_y-r_ys_x.$$

若两坐标同时变成原来的 c 倍，则 `d` 变成 `c²d`，而交点的几何存在性应保持。单位对角线原本 `|d|=2`；取 `c=10^{-7}` 后，`|d|=2×10^{-14}`，被程序的 `10^{-12}` 绝对阈值误判为平行。这不是两个输入“数学上太接近平行”，而是容差没有随尺度变化。x/y 可能具有不同单位，固定坐标距离去重也应声明各轴尺度和应用允许的分辨率。

这不意味着机械改成任意一个相对常数就完成修复。近退化几何仍需要稳健判定；误差界要与所计算的乘积量级、浮点精度及数据意义相配，另需区分真实的相近交点和重复计算同一点。

对于总体式 z-score，令 `z_i=(x_i−μ)/σ`。正比例换单位 `x'_i=c x_i` 应有 `μ'=cμ`、`σ'=cσ`，从而 `z'_i=z_i`。本次 `[1e200,2e200]` 的均值为 `1.5e200`，标准差为 `5e199`，都可表示；直接计算差的平方约为 `2.5e399` 却溢出。**最终答案可表示，不保证中间表达式可表示。** 可以研究先缩放后求平方和的方案；仅把求和改为 Kahan 不能阻止单个平方溢出。

### 6.3 误差条不是一种可以随意命名的线条

对 n 个独立同分布观测，样本标准差 `s` 描述观测离散程度；样本均值标准误常估计为 `s/√n`，描述均值估计的波动。若观测独立且来自正态总体、方差未知，均值的双侧 `1−α` 置信区间可写成

$$\bar x\pm t_{1-\alpha/2,n-1}\frac{s}{\sqrt n}.$$

SD、SEM 和 CI 需要不同标签；相同上下界几何形状不能替代样本量、置信水平和方法说明。配对数据、重复测量相关性或明显不同的误差模型需要重新选择分析方法，不能无条件套用这个区间。

若输出为 `g(u)`，输入随机误差较小且 g 在工作点可微，一阶线性化给出

$$\operatorname{Var}(g(u))\approx J\Sigma J^T,$$

其中 J 为梯度行向量，Σ 为输入协方差矩阵。相关项不能随意省略：若 a、b 实际是同一个测量量，则 `Var(a−b)=0`；把它们误当独立会算成两个方差之和。当前数据模型和公式节点没有传递这类协方差信息，因此不能仅凭存在公式运算就宣称已支持误差传播。

类似地，最小二乘求出了系数，不自动意味着区间正确。在设计矩阵满列秩、独立同方差加性误差模型下，可用残差平方和除以 `n−p` 估计误差方差（还要求 `n>p`），再构造系数协方差。加权拟合、异方差、相关观测、预测新观测与估计均值曲线分别涉及不同条件。这些统计接口应与数值求解器区分，同时保留联系。

**练习 A：** 只把两条交叉线的坐标同时乘 `10^{-7}`，正确交点坐标应怎样变化？交点个数为什么不该变化？

<details><summary>答案</summary>

原交点 `(0.5,0.5)` 应变成 `(5e-8,5e-8)`。正比例缩放是可逆映射，原来相交的两个集合缩放后仍相交，且唯一交点仍唯一。若个数变化，应检查阈值、溢出、截断及数据丢失，而不是解释为物理现象改变。

</details>

**练习 B：** 对本次 `[1e200,2e200]`，把方差求和改成补偿求和，能否单独修复结果？

<details><summary>答案</summary>

不能。误差发生在相加以前：每项约 `2.5e399` 的平方已经成为 Infinity。补偿求和只能缓解可表示有限数相加时的舍入损失。需先改变中间数值尺度或平方和计算方式，再讨论累加误差。

</details>

1. **先处理现有正确性问题。** 保留文本类别与缺失语义，保留分段信息，去掉静默求交截断或给出明确完整性状态，建立尺度合理的几何判定与标准化。每项用上面的独立反例转成真正的预期正确结果回归。

3. **补拟合诊断。** 在现有稳定 QR 基础上输出原观测处预测值、残差、残差平方和、样本数、参数数和模型说明；再按明确误差模型添加权重、参数区间与预测区间。
