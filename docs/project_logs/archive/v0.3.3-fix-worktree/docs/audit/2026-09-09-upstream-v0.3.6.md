# 上游 v0.3.6 复核：哪些旧问题真的修了

日期：2026-09-09。官方标签：[`v0.3.6`](https://github.com/Feathrior/SyphonNov/tree/v0.3.6)，提交：[`3d94ff2a`](https://github.com/Feathrior/SyphonNov/commit/3d94ff2a29709917e8c19b6720a19d06a7f08e8f)。本报告检查官方源码副本，没有把 v0.3.6 合并进本地修复工作树。

GitHub 官方比较显示，v0.3.6 相对本地原基线 v0.3.3 前进 1 个提交，修改 39 个文件，增加 4264 行、删除 1274 行。版本声明为 `0.3.6+1`。下载的官方快照保存在工作区 `.syphon-tools/upstream-v0.3.6/Feathrior-SyphonNov-3d94ff2`，审计另加入一个独立探针文件；它不属于作者发布的源码。

## 结论

**新版有真实的架构和交互改进，但此前发现的大部分科研正确性问题没有修复。** 一个明确修好的数值问题是：线段求交不再因整体缩小到 `1e-7` 而漏掉交点。作者新增了把有限 double 精确转为二进有理数的几何判定，解决了小尺度叉积被固定绝对阈值吞掉的问题。

这项改进没有使整个求交流程都变成“精确算法”：相近交点仍按相对阈值合并，曲线仍只取前 3000 个点，显式函数丢弃非有限样本后仍会跨间断点连线。因此 `1/x` 仍产生不存在的 `(0,0)` 交点。

## v0.3.6 实际新增或改善

- 曲线输入合并为函数、参数方程和隐式方程三种模式；隐式曲线用 NaN 分隔不同折线段，绘制和求交会跳过这些断点。
- 曲线求交新增精确有理数线段判定，小尺度 `1e-7` 交叉实测从漏检变为正确得到 1 个交点。
- 坐标系节点可以收集点、线、面、分布和文字；火山、热力、箱线、小提琴、桑基和网络图可以接入坐标系样式或范围，并新增隐藏坐标轴模式。
- Alt 拖线可自动插入类型转换链；执行引擎增加邻接表、脏节点增量计算、单节点耗时和后台 Isolate 执行。
- 表格输入节点显示文件名，曲线参数按模式隐藏或显示，菜单、缩放控件和滚动区域有较多交互调整。

这些是有效改进，但它们主要解决工作流组织、性能和交互能力，并未系统修改原有数值算法、数据导入器或出版导出。

## 旧反例重新运行

v0.3.6 自带测试实际运行：**88/88 通过**。同一环境对我们原先的四个正确性反例运行，结果 **4/4 失败**：

| 反例 | 正确结果 | v0.3.6 实测 | 状态 |
| --- | ---: | ---: | --- |
| `2*x^2`，`x=3` | 18 | 36 | 未修 |
| `0.0000001*x`，`x=1` | `1e-7` | 0 | 未修 |
| `x=[0,1,3]` 上的 `x²`，中点求导 | 2 | 3 | 未修 |
| 重复横坐标 `(1,1),(1,2)` 求导 | 明确拒绝 | 返回两个结果 | 未修 |

进一步探针得到：

| 检查项 | v0.3.6 实测 | 判断 |
| --- | --- | --- |
| 同一交叉几何缩小到 `1e-7` | 两种尺度都得到 1 个交点 | **已修** |
| 两个相距 `5e-7` 的真实交点 | 合并为 1 个 | 未修；去重阈值仍改变结果 |
| 第 3001 点所在末段求交 | 无交点 | 未修；仍截断 |
| `1/x` 与 `y=0` | 报告 `(0,0)` | 未修；显式函数未保留定义域分段 |
| 完整分类列 `control/treated` 清洗 | 2 行变 0 行 | 未修 |
| `[1e200,2e200]` z-score | `[-0,0]` | 未修；中间平方溢出 |
| 保存随机预设再打开 | 观测值改变 | 未修；只保存生成规则 |
| 坐标范围 `[0,1e-12]` | 变成 `[0,1]` | 未修 |
| 数值 X `[0,1,10]` 的中点位置 | 画在 50%，应为 10% | 未修；仍按等距类别绘制 |
| 普通散点 5001 行 | 只画 5000 行 | 未修 |
| 原理化散点 6001 个 | 只画 6000 个 | 未修 |
| 引号字段内含换行的 CSV | 2 条观测被拆成 3 条并错列 | 未修 |
| 稀疏 XLSX 后行出现 C 列、表头只有 A 列 | `RangeError` | 未修 |

适配新版异步执行的独立工作流探针共 6 项：手动数据保存往返 1 项通过，随机数据复现、微小轴范围、两个点数上限和非均匀数值 X 共 5 项失败。旧的数据探针中两项工作流断言没有等待新版异步队列，不能用其失败判断；上表采用了等待 `GraphStore.settled` 后的适配结果。

## 尚未加入的关键科研能力

v0.3.6 仍没有原生 log/symlog/时间轴、误差条与置信带、拟合残差和参数区间、自动系列图例、多面板与共享轴、批量导出和完整实验包。作者还移除了可连接的色带输入节点；热力图仍可在属性面板编辑渐变，但没有解决跨图固定数值范围与同值同色的问题。

SVG/PDF 固定物理页面、字体嵌入、PNG DPI 元数据等本地修复也没有出现在上游 39 个改动文件中；官方版本仍不能替代当前本地导出实现。

## 测试与集成判断

“88 项通过”只证明作者选择的 88 条断言通过。它没有覆盖上表的量词、尺度和数据语义，因此与这些反例失败并不矛盾。用 Flutter 3.47.2 对官方快照运行静态分析，得到 4 条 `curly_braces_in_flow_control_structures` 信息级问题，无 error 或 warning；分析命令因信息项退出 1。

本地工作树仍保持在 v0.3.3 基线上叠加科研修复，没有自动合并 v0.3.6。新版同时重写 `exec.dart`、`registry.dart`、`graph_store.dart`、`viewer.dart` 和 `principled.dart`，正好与本地修复重叠。后续集成应把新版的隐式/参数曲线、精确求交判定、坐标系收集和增量执行逐项移植到本地修复版，再让全部旧回归与新版测试共同通过；直接覆盖会重新引入已修复的科研错误。

Flutter SDK 路径迁移后，本地修复版已用新路径完成依赖解析、静态分析、111 项测试和 Windows Release 构建；见 [迁移验证](../verification/flutter-relocation-2026-09-09.md)。因此本报告中的 v0.3.6 失败不能归因于 Flutter 路径或 C++ 工具链不可用。
