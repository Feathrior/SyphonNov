## 判断

**目前不完备，不能声称具备全部科研绘图功能，也尚不足以可靠覆盖常见科研图的完整制作流程。** 它已有可扩展的节点工作流、基础二维图与三维投影图元、基础数值计算和三种导出格式；但仍有会改变数据或图形含义的现存缺陷，并缺少不确定度表达、充分的坐标控制、拟合诊断和论文组合排版。

评价“完备”需要限定工作流。本文按“数据进入 → 清洗与计算 → 统计与不确定度 → 可比较的图形 → 排版导出 → 实验复现”检查常用需求，不要求一个绘图工具内置所有学科分析算法。外部 Python/R 或专用软件完成分析后再导入结果是合理途径，但导入、图形表达和参数语义仍必须可靠。

上一轮 **111 项回归通过**只覆盖当时的测试集合，不是全面功能认证。本轮新增反例已经说明，两者不能等同。

| 能力 | 评价 | 可以合理使用的范围 |

## 应优先修复的现存问题

下表给出直接调用当前代码得到的反例。它们属于已有功能的正确性问题，优先级高于增加更多图表名称。

| 问题 | 实际结果 | 为什么关键 |
| --- | --- | --- |
| 分类字段被当成缺失 | `group=[control,treated]`、`response=[1,2]`，没有空值，清洗后 **2 行变 0 行** | 分组实验数据会被误删 |
| CSV 与稀疏 XLSX 边界 | 含引号内换行的两行 CSV 变成三行并错配数值；后行列数多于表头的 XLSX 抛 RangeError | 数据在计算开始前已经损坏或无法进入 |
| 函数间断点丢失 | `1/x` 跨零采样后被连成一段，与 `y=0` 求交得到不存在的 **(0,0)** | 输出可能具有错误数学含义 |
| 求交的尺度与截断 | 同一交叉几何缩小 `1e-7` 后交点消失；相近交点被合并；第 3001 点所在末段被忽略 | 单位和规模改变会改变答案 |
| 原理化坐标及数据上限 | 请求范围 `[0,1e-12]` 被改为 `[0,1]`；6001 个点只绘 6000 个；相对居中注释偏移 | 第一轮对普通二维图的修复没有覆盖这些独立路径 |
| 标准化中间量溢出 | `[1e200,2e200]` 的 z-score 为 `[-0,0]`，正确应为 `[-1,1]` | 输入和答案都可表示，中间平方却溢出 |
| 保存随机预设后重新打开 | 同一 JSON 生成不同观测值；手动数据对照则保持不变 | 保存了生成规则，尚未保存当次实验数据 |

证据分为三份：[数据与复现](audit/2026-09-06-data-workflow.md)、[计算与统计](audit/2026-09-06-numerical-statistical.md)、[绘图与导出](audit/2026-09-06-plot-export.md)。其中都有源码位置和可运行诊断。

## 常见科研流程的关键能力缺口

| 优先级 | 缺口或不足 | 典型受影响任务 | 最小完成标准 |
| --- | --- | --- | --- |
| 高 | **误差条、置信带及其数据语义** | 重复实验、标定曲线、模型预测 | 接入 x/y 对称或非对称误差、SD/SEM/CI 类型、样本量与置信水平；支持外部算好的区间，也可逐步添加分组统计 |
| 高 | **原生 log/log-log/symlog、时间轴、等比例坐标** | 数值分析收敛阶、频谱、时间序列、几何比较 | 坐标类型控制统一作用于主图、叠加、刻度与拾取；日期按真实时长映射；等比例选项有几何回归。提前对数据取 log 是可行变换，但不等于原生对数轴 |
| 高 | **自动图例、多面板与统一排版** | 多方法比较、论文 a/b/c 子图 | 系列名称与样式自动绑定图例，支持图格、共享轴/色标、统一字号边距与面板标号；节点分组不能替代论文子图布局 |
| 高 | **拟合诊断与不确定度** | 实验回归、算法误差分析 | 输出观测处预测、残差、样本数和自由度；明确误差模型后提供权重、参数区间、置信带/预测带。点大小“权重”不是统计权重 |
| 高 | **跨图可比较的统计图语义** | 多组热图、分布比较和显著性图 | 固定色标范围及越界规则，明确计数/密度归一化；箱线须、KDE 带宽、火山图阈值和 p 值来源可声明。当前给相同色带范围，不保证不同热图中的同值同色 |
| 中 | **可复现实验包与批量执行** | 同一模板绘制多样本、多参数实验 | 保存原数据或可重建生成状态、版本与摘要；提供批量入口、失败报告和统一导出配置 |
| 中 | **数据导入与后台执行的工程完整性** | 多工作表、混合字段、较大数据量 | 明确表头/类型/编码/工作表选项，严格校验工作流；长任务可取消、按需计算并设置性能测试门槛 |

这些需求的选择有现实工作流依据。例如，Matplotlib 分别提供 [误差条](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.errorbar.html)和[共享轴子图布局](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.subplots.html)，SciPy 的 [curve_fit](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.curve_fit.html) 将测量标准差/协方差和拟合参数协方差作为明确接口。它们是本次比较的具体能力例子，不是一份必须照搬的“全部功能”清单。

## 针对数值分析学习的下一轮顺序

1. 先修数据清洗/导入、间断点和求交、原理化微小范围及截断，避免用错误图形学习正确数学。
2. 再补 log-log 收敛图、等比例坐标、误差曲线比较、残差输出、X 感知插值，以及记录算法版本与输入的实验包。
3. 接着补多面板、共享图例和误差条/置信带，完善实际报告制作流程。
4. 等目标研究方向明确后，再选频谱、等高线/向量场、ODE/PDE、专业文件格式等领域扩展。直方图目前只有未接入用户流程的辅助函数和部分分布图元，也需要补成有明确计数/密度语义的功能。

学习配套新增 [测试覆盖与数据语义](learning/06-测试覆盖与数据语义.md)，数值审计还给出介值定理条件、行列式尺度、标准化溢出及 SD/SEM/CI 的推导与练习。本轮反例是待修学习材料，尚未记为修复完成。
