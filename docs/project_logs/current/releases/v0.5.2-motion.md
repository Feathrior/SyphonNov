# SyphonNov v0.5.2+2 动效更新记录

日期：2026-09-11  
基线：GitHub `v0.5.2`（`a4c7bd4668528695057cd6c919ee002ad2066806`）

## 圆环入场

- 将圆环入场改为由自身 `AnimationController` 驱动，画布指针更新与父组件重建不会让动画重新起步。
- 完整档从最终尺寸的 `0.75%` 开始，经过 `110.5%` 的轻微越界后回落到 `100%`。
- 初始旋转提高到约 `210.6°`，在总入场时长的前 `2/3` 完成；与上一版相比转角和平均角速度提高 `50%`。
- 峰值高斯模糊由 `30px` 提高到 `45px`，与缩放、旋转和透明度共用同一时间轴。
- 圆点从色环分离时使用有界非线性橡皮筋函数，距离越远阻力越强，不再使用固定比例位移。

## 三档动效幅度

- 完整：缩放、位移、旋转和模糊使用 `100%` 幅度。
- 简化：上述空间动效统一缩减为 `42%`，并继续使用 v0.5.2 的简化时长。
- 关闭：组件直接呈现最终静态状态，不留下初始透明、模糊或缩小帧。
- 快速、适中、慢速三档速度继续通过 `MotionSpeed` 缩放动画时长，与幅度设置相互独立。

## 统一交互轨迹

- 传统右键菜单增加从触发点附近生长的弹性缩放、上移和短时模糊。
- 顶部书脊库切换增加越界回弹与位移，书脊悬停使用回弹曲线。
- 书脊拖出指示环保留条形到圆形的形变，并增加缩放、旋转与模糊入场。
- 属性分类展开使用单调缩放和模糊，避免回弹改变命中区域。
