## 核心能力

- 节点化数据导入、清洗、数值计算、转换和二维、三维科研绘图。
- 显式曲面、参数曲面、曲面预设、曲线与曲面求交，以及带 LOD 的三维预览。
- 对数与时间尺度、误差条、置信带、图例、SVG、PDF 和高分辨率 PNG 导出。
- 顶部书脊节点架、传统右键菜单、六向色环菜单和统一的缩放、模糊、旋转动画。
- 可折叠、可复用并保留外部接口的 Package；支持文件直接拖入画布。
- 点击输出预览可恢复输出节点选择，并继续使用右下角缩放柄。
- 色环使用独立、不可被指针重建打断的入场时间轴：从 1.5% 尺寸开始，伴随约 140° 旋转和 30px 高斯模糊放大，轻微越界后稳定在完整尺寸。
- 色环在相同转角下将旋转阶段压缩至原来的 2/3，角速度提高 50%；节点分离采用随距离增强的非线性橡皮筋阻力。
- 顶部书脊悬停、书脊面板切换、拖出圆点、新节点落位、传统右键菜单、顶部菜单和属性浮层统一采用弹性缩放、位移与短时动态模糊。
