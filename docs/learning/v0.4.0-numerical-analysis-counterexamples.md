# SyphonNov v0.4.0 数值分析与工程反例教学记录

## 1. 稳定方差：为什么“先平方再求和”会失败

对 `x=[1e200,2e200]`，直接计算 `Σ(xᵢ-x̄)²` 会产生约 `1e400` 的中间量，超过 IEEE-754 double 的约 `1.8e308` 上限。输入全部有限，结果却因中间表达式溢出而退化。

v0.4.0 先按最大绝对值缩放，再用 Welford 更新：`δ=xₙ-μₙ₋₁`，`μₙ=μₙ₋₁+δ/n`，`M2ₙ=M2ₙ₋₁+δ(xₙ-μₙ)`。它避免“大数平方”，同时减少 `E[x²]-E[x]²` 的灾难性消减。回归反例要求 `[1e200,2e200]` 的总体 z-score 为 `[-1,1]`。

## 2. 缩放部分主元：零不是固定的 `1e-12`

方程 `diag(1e-20,1e-20)x=[1e-20,2e-20]` 与两边同乘 `1e20` 后完全等价，解应始终是 `[1,2]`。固定阈值把 `1e-20` 当零，破坏了尺度不变性。

缩放部分主元比较 `|aᵢk| / maxⱼ|aᵢj|`，再用与矩阵尺度、维度和机器精度有关的相对阈值判秩。若秩小于未知数个数，v0.4.0 明确拒绝“唯一解”，不会用初始化的零补出一个伪解。

## 3. QR 拟合：正规方程会平方条件数

多项式最小二乘若构造 `AᵀA c=Aᵀy`，条件数满足 `κ(AᵀA)≈κ(A)²`。当 X 很大、次数较高或采样点接近时，原本勉强可解的问题会损失两倍数量级的有效数字。

v0.4.0 对中心化、缩放后的设计矩阵直接做 QR，并检测不足数据和数值秩。反例要点是：重复 X 或列近相关时必须报告病态/奇异，不能返回看似正常的系数。

## 4. 非均匀三点差分

在 `x₀,x₁,x₂` 不等距时，中点导数不能写成 `(y₂-y₀)/(x₂-x₀)`。用经过三点的二次 Lagrange 插值多项式求导，可得依赖 `h₀=x₁-x₀` 与 `h₁=x₂-x₁` 的三个权重。反例 `x=[0,1,3], y=x²` 中，跨点割线给 3，而插值导数在 `x=1` 给 2。

重复、逆序或非有限 X 破坏了该公式的前提，因此实现先验证严格递增，再计算端点单边三点式和内部三点式。

## 5. 间断曲线：NaN 是拓扑信息

采样 `1/x` 时删掉 `x=0` 的无效点，会把左右两支变成相邻点，绘图和求交便虚构一条跨越渐近线的线段。v0.4.0 保存 NaN 分隔符；绘制、求导、积分、拟合和求交都把它当作“结束当前连续段”。

这里 NaN 不代表一个待计算的数，而是序列拓扑中的断段标记。任何逐点过滤若丢掉它，都会改变曲线的连通性。

## 6. 包围盒层次求交

两条各含 n、m 段的折线直接两两比较需要 `O(nm)` 次候选检查。旧版用截掉第 3000 点来控制时间，代价是结果错误。

v0.4.0 为完整 B 曲线建立轴对齐包围盒层次树。查询 A 的一段时，整棵不相交的子树可一次排除；叶节点才进入精确线段测试。最坏情况仍可能退化，但普通局部曲线接近 `O((n+m)log m+k)`，其中 k 是候选重叠数。NaN 两侧从不生成线段。

## 7. LOD：预览近似不能污染计算

折线预览按桶保留首尾、Y 极小、Y 极大和全部 NaN 缺口；散点按像素网格聚合，并保留首末观测。界面显示 `LOD 显示数/原始数`。这保证峰值、端点和断段不会因抽样消失。

LOD 只用于交互预览。执行结果和 PNG 导出继续消费完整数据。若把 LOD 数据写回节点输出，后续积分、交点和拟合都会在用户不知情时改变，因此数据层和视图层必须分开。

## 8. 异步 revision：串行不等于一致

初始 `a=1,b=10`，连续编辑为 `a=2`、`b=20`。若第二个任务在排队时捕获旧 results，即使任务串行执行，也可能最后提交 `a=1,b=20`。

v0.4.0 为每次请求分配单调 revision。worker 结果只有在 revision 等于最新请求时才能提交；较新的任务按最新图快照做完整合并运行。取消操作通过提升 revision 使在途结果失效。结构化状态暴露 `revision/status/progress/error`，Isolate 失败不会退回 UI 线程。

## 9. 可复现实验的随机数

“同一分布”不等于“同一数据”。工作流只保存分布参数，重载后会得到另一批点。v0.4.0 把 seed 作为节点参数保存；v0.3.6 文件缺 seed 时由节点 ID 稳定迁移出 seed。保存、重载和再次执行必须逐值一致。
