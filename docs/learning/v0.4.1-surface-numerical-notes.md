# v0.4.1 曲面数值分析教学记录

## 1. 曲面不是“许多独立三角形”

显式曲面先在规则参数网格上采样顶点，再把每个四边形按一致绕序拆成两个三角形。绕序决定法向量方向。若相邻单元随意交换顶点顺序，叉积方向会反转，光照或后续几何算法会出现棋盘状跳变。

反例：对 `z=x²-y²` 的 3×3 网格随机翻转一个三角形。该面的法向量会与邻面相反；累加到共享顶点后还可能相互抵消。v0.4.1 固定使用 `(q0,q1,q2)` 和 `(q0,q2,q3)`。

## 2. 非有限值表达的是定义域孔洞

对 `z=1/(x²+y²)`，原点不是一个“很高的普通点”。把无穷值删除后再连接剩余邻点，会制造跨奇点的假面。正确做法是保留原采样位置的无效标记，并拒绝任何引用无效角点的单元。

这和一维曲线用 NaN 断段是同一个原则：缺失值既携带“没有数值”，也携带“这里不能连接”的拓扑信息。

## 3. 参数接缝与重复端点

球面经度 `u=0` 与 `u=2π` 表示同一条接缝。若两个端点都采样，会产生重复顶点和零宽单元；若只删终点却不连接首尾，又会留下裂缝。周期采样应取 `u_i=u_min+(u_max-u_min)i/n`，`i=0,…,n-1`，最后一列用模运算连回第 0 列。

球极点仍是参数坐标的退化位置：许多参数点映到同一空间点。当前网格保留这些顶点以维持规则索引，法向量由相邻非退化面累加得到。需要高质量有限元网格时，应进一步做极点合并和重三角化。

## 4. 法向量为何要面积加权

三角形两边 `a=b-p`、`c=q-p` 的叉积 `a×c` 方向垂直于面，长度等于平行四边形面积。直接累加未归一化叉积，再对总和归一化，会让大三角形贡献更大。这比“先把每个面法向量单位化再平均”更符合局部面积权重。

退化三角形的叉积为零，不应除以零。v0.4.1 只在累积向量长度为正且有限时归一化。

## 5. 表格重建为何要拒绝重复坐标

长表中的两个 `(x,y)` 若对应不同 `z`，程序无法知道应该平均、覆盖还是把它们当作两层曲面。静默取最后一个会使结果依赖输入行顺序。v0.4.1 因而拒绝重复坐标；若实验确实有重复测量，应先在独立聚合节点里明确选择均值、中位数或保留多层语义。

缺失网格点则不同：它表示已知规则坐标中没有观测，因而保留为孔洞。

## 6. equal/data aspect 的量纲意义

自由坐标盒把每个轴分别拉满，半径相同的球会因 X/Y/Z 范围或盒长不同而看成椭球。equal/data 模式计算

`s = min(Lx/Δx, Ly/Δy, Lz/Δz)`，再令 `L'x=sΔx`、`L'y=sΔy`、`L'z=sΔz`。

于是三轴上一个数据单位都对应同一物理长度。它保证几何形状，却可能在某些方向留下空白；这是保持比例必需的代价。

## 7. LOD 与数值结果必须分离

预览抽样若覆盖原网格，会让导出、积分或求交随窗口大小变化。v0.4.1 在 `MeshData` 中始终保存全量顶点和三角形，另存预览面预算。交互 Painter 才应用预算；固定尺寸导出绕过它。

反例检验：同一个 400×400 曲面缩小窗口后，预览三角形数可下降，但 `sourceFaceCount`、下游数据和导出的全量面数必须不变。
