# v0.4.2 数值分析教学记录：尺度、不确定性与导出

## 1. 对数坐标改变的是映射，不是数据

对数轴将数值 `x` 映射为 `log_b(x)` 后再做线性归一化。数据 `1, 10, 100` 在 log10 轴上等距，但原数据仍然是 `1, 10, 100`。求导、积分或拟合若需要在对数域进行，必须由计算节点明确完成变量变换，不能由绘图轴暗中改变。

反例：把 `x=-1, 1` 连在 log10 轴上。`log(-1)` 没有实数值，若渲染器把它夹到一个很小正数，图中会产生一条虚假长线。v0.4.2 让该点的变换结果成为 NaN，并沿用统一断段语义。

## 2. Symlog 为什么需要线性阈值

纯对数不能显示 0 和负数。Symlog 使用

`sign(x) log(1 + |x| / c)`

其中 `c` 是线性阈值。零点附近近似 `x/c`，远离零点后逐渐呈对数压缩。`c` 太小会让噪声被夸大，太大则接近线性轴。它是数据解释参数，应和图一起保存。

反例：同一份残差数据用 `c=10^-6` 和 `c=1` 绘制。前者会让接近机器噪声的差异占据大量屏幕距离；后者更适合观察正负残差的整体结构。

## 3. SD、SE、CI 和 PI 不能只画成同一种“误差条”

- SD 描述观测值的离散程度。
- SE 描述估计量的抽样不确定性，常见形式是 `SD/sqrt(n)`。
- CI 给参数或均值的区间估计。
- PI 预测下一次观测可能落入的范围，通常比均值 CI 更宽。

反例：样本量从 25 增到 100，数据分布不变。SD 大致不变，SE 约缩小一半。若图只保存上下界而不保存语义，读者无法判断窄区间来自更稳定的数据还是更大的样本量。因此 `SeriesData` 同时保存 `uncertaintyKind` 和 `uncertaintySource`，导出 manifest 也保留它们。

## 4. 非对称误差不能被强制平均

比率、浓度和指数模型的区间常在原尺度上不对称。例如估计值 10 的区间可能是 `[8, 15]`，向下误差为 2，向上误差为 5。把它改成 `±3.5` 会改变端点，并可能越过物理下界。v0.4.2 分别保存 X/Y 的 minus 和 plus；只给 minus 时才按明确的对称约定复制到 plus。

## 5. 区间带也必须遵守缺失断段

反例：两个实验批次之间有一行缺失值。若先丢掉缺失行再拼接上下界，多边形会跨越空白区域，暗示那里存在连续置信区间。正确做法是分别积累连续的上边界与下边界，每遇到 NaN 就封闭当前多边形并开始新的一段。

## 6. DPI、像素和物理尺寸的关系

`pixels = inches × DPI = millimetres / 25.4 × DPI`

89 mm 的期刊单栏图在 300 DPI 下约为 1051 像素。像素数组本身不能完整表达印刷尺寸，所以 PNG 还需写入 pHYs 元数据；PDF 则用 point 定义页面，`1 inch = 72 points`。manifest 记录用户请求和换算结果，便于核查投稿系统是否重采样。

反例：同一个 1051 像素 PNG 若分别被解释为 300 DPI 和 96 DPI，印刷宽度约为 89 mm 与 278 mm。图像内容完全相同，物理语义却不同。

## 7. 后端无关场景为什么能防止预览和导出分叉

如果 Canvas、SVG 和 PDF 各自计算坐标，修复 log 轴时很容易只改其中一个。v0.4.2 先把坐标尺度、3D 旋转、断段和样式变成场景命令，再由导出器序列化。测试用竖直三角形反例检查两个 XY 相同但 Z 不同的顶点；若导出器忽略 Z，这两个顶点会重合，曲面退化。

字体是当前明确边界：PDF 可以子集嵌入字体，但所用库不能直接把每个字形变成轮廓路径。请求轮廓化时程序会回退嵌入并记录，而不是把“已请求”误写成“已完成”。

## 8. 数据原点不等于视图盒中心

反例：令 X 范围为 `[-2, 8]`、Y 范围为 `[-1, 9]`。视图盒中心对应数据点 `(3, 4)`，若直接在局部几何坐标 `(0, 0)` 画轴，坐标轴会错误地交于 `(3, 4)`。正确做法是先在数据域选择交点 0，再经过与曲线相同的尺度变换映射到视图。若范围为 `[2, 8]`，0 不在定义域内，轴退到边界 2；对数尺度也采用这一规则。

## 9. 三维网格是三个方向族

三维网格不能只画底面上的 X、Z 两组线。Y 刻度对应的线族至少需要出现在一个可见基准面上，否则切换“Y 方向网格”不会产生任何结果。修正后的每个方向族画在相邻的两个基准面上，并让预览与矢量导出使用相同的开关语义。
