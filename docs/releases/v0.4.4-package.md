# SyphonNov v0.4.4 Package 与文件拖放更新日志

发布日期：2026-09-10  
分支：`feature/v0.4.3-interaction`  
版本：`0.4.4+2`

## 用户可见变化

- 顶部节点库的书脊文字改为字符直立的纵向排版；展开框按当前分类的节点数量收缩，短分类不再留下大片空白。
- Delete 与 Backspace 恢复为画布固定删除入口；用户自定义的删除快捷键作为额外入口保留。
- 从资源管理器拖入 CSV、TSV、TXT 或 XLSX 时，在投放位置自动生成“表格输入”节点，节点名称使用文件名；多文件按 32px 间距错开放置。
- 新增灰色 Package：Shift 多选节点后，可从右键菜单命名并打包。折叠时显示一个灰色代理节点，自动暴露子图边界输入/输出端口；内部子图继续参与执行，外部连线重定向到对应代理端口。
- Package 右键可以展开或折叠；展开后显示原始节点与连线，并由灰色虚线框包围。
- Package 可保存到持久化库，从顶部 Package 标签或画布右键菜单再次实例化；顶部库支持删除模板。
- 不同节点分类之间切换时，弹层宽度会平滑插值，内容同步淡化、缩放并由模糊恢复清晰。
- 顶部节点始终遵循注册表中的固定顺序；收藏和最近使用不再改变书脊位置。
- Package 明确显示“前置输入”和“后续输出”，端口名称同时标出内部节点与插槽，折叠前后的外部连线保持不变。
- 全局快速、标准和空间动效分别调整为 110ms、230ms 和 320ms，使状态变化更容易跟随。

## 数据与兼容性

- Package 元数据随工作流 JSON 保存；普通 v0.4.x 分组仍按原格式加载。
- Package 库保存在应用 `settings.json`，模板实例化时为节点和连线生成新 ID，避免与当前画布冲突。
- 修正 Win32 `WM_DROPFILES` 坐标被二次转换的问题，并修复 UTF-16 文件路径缓冲区末尾写入越界。
