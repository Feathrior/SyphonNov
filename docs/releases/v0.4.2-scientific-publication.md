# SyphonNov v0.4.2 科研表达与论文导出更新日志

日期：2026-09-10  
分支：`feature/v0.4.2-publication`

## 发布结论

v0.4.2 把坐标尺度、统计不确定性、图例和论文导出接入同一套 `AxesData` 语义。预览、SVG 和 PDF 使用相同的尺度变换与断段规则；PNG 同时写入 pHYs 物理分辨率和 JSON manifest。

本次也降低了曲面默认绘制负担，并固定右键输入节点的首要顺序。

## 用户可见变化

- 曲面默认 U/X、V/Y 采样从 61×61 调为 31×31，隐式 Z 采样为 25，预览面预算从 12000 调为 6000。
- 曲面默认显示为实体面，网格边线按需开启；“面透明度”改名为语义准确的“面不透明度”，默认值从 0.85 降为 0.6。
- 右键节点菜单的输入分类固定先显示“点输入、曲线输入、曲面输入”。
- 坐标系新增 linear、log10、log2、symlog 和 Unix 毫秒时间尺度。对数轴范围含非正数时执行失败；单个非正数据点作为缺失断点。
- 新增“误差与区间”节点，支持对称或非对称 X/Y 误差条、CI/PI 区间带，以及 SD、SE、CI、PI、自定义来源元数据。
- 图例支持自动或手动顺序、按图元类型分组、按名称隐藏，以及左、右、底部位置。
- 原理化输出新增 SVG 与 PDF；2D/3D 点、曲线、曲面均经过同一场景树，3D 矢量导出保留 Z 投影。
- 导出尺寸支持 px、mm、inch 和 DPI；提供期刊单栏、双栏、海报、演示文稿预设。
- PNG 写入 pHYs 块；PNG/SVG/PDF 均生成并排的 `.manifest.json`，记录尺寸、DPI、尺度、字体策略和不确定性来源。

## 兼容性与限制

- 工作流 schema 仍为 v2；新增坐标系和误差参数都有默认值，v0.4.1 文件可直接加载。
- `log` 在数据层等价于 `log10`；界面公开 `log10` 和 `log2`，避免底数不明确。
- 时间轴输入目前是 Unix 毫秒数，尚无时区和日期字符串解析节点。
- PDF 的“轮廓化”请求在当前 Dart PDF 后端无法直接取得字形路径时，会回退为字体子集嵌入，并在 manifest 中写明；不会伪称已经轮廓化。
- Windows 默认使用系统中的 `simhei.ttf` 或 `simsunb.ttf` 进行 Unicode 子集嵌入。若目标系统缺少这些字体，manifest 会报告核心字体回退；SVG 始终保留可编辑 Unicode 文本。
- 透明曲面的矢量面片仍采用面顺序合成；相互穿插的半透明三角形受 painter 顺序限制。
