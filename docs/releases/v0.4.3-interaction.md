# SyphonNov v0.4.3 交互体验更新日志

发布日期：2026-09-10  
分支：`feature/v0.4.3-interaction`  
版本：`0.4.3+3`

## 用户可见变化

- 顶栏下方新增 42px 固定节点提示条，五类节点直接读取注册表和 `kCategoryInfo`；展开的节点库使用独立浮层，不会推动或反复布局画布。
- 鼠标悬停分类平滑展开节点库，离开分类与浮层之间保留 120ms 容错；浮层使用缩放、淡入和由模糊到清晰的统一进入与退出动画。
- 展开层删除重复的搜索框与五个分类筛选按钮，类别直接由顶部提示条决定；节点改为横向排列的窄书脊，只显示本地化名称与图标，不再显示英文 ID。
- 节点可直接单击创建在视口中心，也可拖入画布。拖动反馈是分类色圆点，画布用独立光环显示合法落点；画布外、Esc 或右键取消均不改工作流。
- 放下坐标经过窗口坐标、画布局部坐标和 pan/zoom 世界坐标的统一换算。画布边缘放置会保留 12px 安全边距，可选 20 单位网格吸附。
- 新节点从圆点以缩放、淡入和动态清晰化展开成完整卡片。节点层以节点 ID 保持稳定身份，选中导致的重排不会使周围节点重播入场动画。
- Alt 自动类型转换把源节点、转换节点和目标节点整理成同向等距链条，再将整条链作为整体避开无关节点并平滑过渡。
- 每个最终可视化输出节点增加右下角缩放柄，可调整节点宽度和图窗高度；尺寸保存进工作流，缩放过程不触发数值执行。
- 快捷键面板支持单击按键后重新录入组合键、冲突交换和恢复默认，绑定持久化到 `settings.json`；新增 `Ctrl+A` 全选与 `Ctrl+X` 剪切。

## 动效与无障碍

- 新增统一 `MotionTokens`，提供 90/180/260ms 三档节奏与平滑减速曲线。
- 文件、编辑、视图、帮助次级菜单，画布右键菜单和右侧属性内容均补齐进入与退出动画；弹出内容采用同一套缩放、淡入和动态清晰化视觉。
- 右侧每个属性分类补上可逆的高度、透明度、箭头旋转和模糊转清晰动画，折叠结束后才移除内容。
- 模糊滤镜只在过渡帧启用，完成后自动移除；“关闭动态效果”时所有过渡即时完成。
- 设置面板新增“完整 / 简化 / 关闭”三档动态效果，并读取系统 `disableAnimations`。关闭后功能和键盘路径保持可用。
- 顶部分类和节点条目支持焦点、Enter/Space 与 Tab 导航；Esc 关闭节点浮层或取消正在进行的创建。

## 性能边界

- 节点库是 Overlay，不进入主内容 Column 的展开布局。
- 拖放合法性提示由独立 `ValueNotifier`、`AnimatedBuilder` 和 `RepaintBoundary` 驱动；移动圆点时不调用 `GraphStore.notifyListeners`，也不重建节点世界。
- 成功拖放只调用一次 `addNode`，因此只有一个 undo 快照和一次 auto-run；边缘夹紧只更新布局。
- 斥力布局只在 Alt 补链完成时求解；动画期间通过轻量 `layoutRevision` 更新位置，不重复执行数值管线。
- 输出节点缩放通过节点专属几何 revision 重建，其他节点和三维查看器不会随指针每帧重建。
